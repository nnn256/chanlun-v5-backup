# 《一小时漫画缠论实战法》学习复习与画线算法

整理日期：2026-11-10。来源为用户提供的管鹏著 EPUB，人民邮电出版社，2022年4月，ISBN 978-7-115-58787-9。章节定位使用 EPUB 内部文件与图资源编号；电子书没有稳定的纸书页码，因此不编造页数。

**先记这一条主线：原始K线 → 处理包含 → 分型 → 笔 → 线段 → 中枢 → 走势类型 → 同级别力度比较 → 多级别确认。**

本笔记把三个层次分开：**【书中】**是本书实际讲解，**【工程约定】**是让算法可重复所固定的选择，**【补充/代理】**是本书省略而借用现有研究引擎实现的部分。整体算法模式为 `structure_proxy`，不把自动画线或指标背离直接认定为严格买卖点。

## 二、手工画线：固定顺序

### 1. 先把输入固定

记录证券、数据源、周期、复权口径、历史起点、截止时间、最后一根K线是否已收盘。同一行情换复权、起点或价格精度，线可能不同；只有图形截图时，不能假装拥有逐根数据。

学习初期只选一个周期练结构。多周期各自建结构，再对齐时间，不能把多个周期的拐点混在一条笔链里。

### 2. 包含：先判断方向，再合并

【书中】只看每根K线的最高价H、最低价L，包含影线。相邻区间满足以下任一条件才是包含：

```text
H1 >= H2 且 L1 <= L2
或 H2 >= H1 且 L2 <= L1
```

部分交叠不等于包含。例如 `[10,18]` 与 `[12,20]` 只是交叠；`[10,18]` 与 `[12,16]` 才是包含。

| 进入包含前的方向 | 合并最高价 | 合并最低价 | 记忆 |
| --- | --- | --- | --- |
| 向上 | `max(H1,H2)` | `max(L1,L2)` | 高高、低高 |
| 向下 | `min(H1,H2)` | `min(L1,L2)` | 高低、低低 |

按时间从左到右依次处理；发生合并后回查左侧，不任意重排。高点和低点可来自不同原始K线，必须分别保存来源。

【工程约定】等高或等低也进入包含；同价极值保留最早来源。序列开头没有前置方向时，本次复用引擎比较包含两项的价格中点，中点相等再比较收盘价；这是初始化约定，**不是本书给出的定理**。收盘价只参与这项初始化，不参与后续分型公式。可从更早的历史起点复核初始化敏感性。

数值练习：已知向上，`[10,18]` 与 `[12,16]` 合并为 `[12,18]`；已知向下则为 `[10,16]`。

来源：第2章“包含”，`text/6.html`；图 `31`、`33`、`34`。

### 3. 分型：比较三个处理后的标准区间

【书中】顶分型中间高，底分型中间低。编码时同时检查高、低，不能只比较最高价：

```text
顶：H中 > H左 且 H中 > H右 且 L中 > L左 且 L中 > L右
底：H中 < H左 且 H中 < H右 且 L中 < L左 且 L中 < L右
```

【工程约定】使用严格不等号，等号不算独立分型。只有右侧标准K线出现并取得有效依据，才看得见分型；右侧未收盘或随后包含重组时，标记仍可能变化。

顶标在中间标准K线高点的原始来源上，底标在低点来源上。**标记所在时间是极值时间，识别它的时间更晚。**

分型只描述局部结构，不自动等于买卖点，也不证明后面一定反转。

### 4. 笔：异类端点、间隔足够、连续衔接

【书中】向上笔连底到顶，向下笔连顶到底；同类分型不互连；两笔交替且共享转折端点；不足间隔的反向摆动不让旧笔结束。

**“最少5根”要这样数。** 书中图 `epub_43946839_47.jpg` 把分型中心到另一分型中心依次标为1—5，而两侧确认分型的K线画在编号外。与正文“两个完整分型之间至少一根独立K线”合并理解：

```text
标准K线编号：  0   1   2   3   4   5   6
底分型支撑： [ 0   1   2 ]
顶分型支撑：                 [ 4   5   6 ]
独立中间K线：             3
笔的中心端点：    1  ───────────  5
中心至中心含端点：1、2、3、4、5，共5根
两个完整分型支撑：0至6，共7根
```

因此本次严格间隔为：**两端分型中心的标准K线编号之差 ≥ 4**。不能误写成“任意5根原始K线里必定存在一笔”；包含合并后的标准K线数量才是这一计数的依据。编号差3不够，因为两个分型之间没有独立K线。

【工程约定】本次用现有引擎的 `stroke_mode='strict'`：按标准K线中心计数；顶中心最高价还须高于底中心最高价。后者来自现有StructGuide规则实现，并非本书逐条形式化的全部价格条件；本书没有完整覆盖同价与所有极端边界，不能据此宣称完全等价。

同类候选顶出现更高顶，更新末端；同类候选底出现更低底，更新末端。同价保留较早位置。`A→B`合法后先画候选笔，等`B→C`也能组成合法反向笔，才确认`A→B`；此时`B→C`仍可待确认，不必等它自己确认。

来源：第2章“笔”，尤其图 `42`、`46—53`；第10章“独立组件”。

### 5. 线段：三笔起步，不能三笔一切

【书中】至少三笔；起始三笔应有共同价格区间；向上段首尾都是向上笔，向下段镜像；反向线段出现才结束旧段。由交替笔组成且首尾同向，笔数自然为奇数。

前三笔各自区间为`[Li,Hi]`，先算：

```text
共同下界 = max(L1,L2,L3)
共同上界 = min(H1,H2,H3)
```

【工程约定】要求共同上界大于共同下界；只有一个共同价的零宽区间不算。满足起始三笔条件只是候选段，后续笔不必始终停留在这个初始交集内。

**本书的缺口：**第3章图`83—86`介绍了“特征序列”的想法，但随后明确略去其细则。因此仅用本书文字无法唯一编码所有线段终结情况。

【补充】本次复用已有 `chanmodel/segments.py` 的研究实现：

1. 向上段抽取向下笔的区间，向下段抽取向上笔，作为特征元素。
2. 按局部方向处理特征元素的包含，再寻找顶/底特征分型。
3. 第一特征序列无缺口时，满足完整候选条件后取得确认依据。
4. 有缺口时，继续等待反向第二特征序列，期间若旧极值被突破则候选失效。
5. 引擎还保留公开规则中的“第一反向笔破坏、后续严格越界”路径；一次刺穿不立即宣布线段结束。

这部分属于**既有公开规则补充**，不是管鹏本书完整给出的算法，也不宣称覆盖缠论原文所有版本差异。

数值例：笔端点`10→20→12→25→15→22→13`，反向特征区间为`[12,20]、[15,25]、[13,22]`；中间形成顶分型，无缺口。读到13附近取得确认依据，旧段终点仍画在25，不能把“已确认”时间倒写到25当时。

### 6. 中枢：先说构件，再画交集

【书中】第4章用“进入段＋至少三段主体＋离开段”说明完整画法；核心边界取前三个主体构件：

```text
ZD = max(L1,L2,L3)  # 低点中的最高
ZG = min(H1,H2,H3)  # 高点中的最低
```

本书也介绍笔中枢：把组成单位从线段换成笔，画法相似。上升背景中主体常用“下—上—下”，下降背景镜像。

要区分三个时点：**三构件核心形成、具有进入/离开的完整观察结构、离开后回试不再返回。** 后两者需要更多走势；不能看到三个交叠构件，就声称旧中枢已经终结。

【工程约定】回放主图的矩形使用**已确认线段**的实际覆盖高低价，要求`ZG>ZD`；前三段确定核心后保持ZG/ZD，后续延伸不把交集越缩越窄。`GG/DD`记录成员整体最高/最低，与核心边界不同。图中矩形是结构研究代理，不是已证明的“完成次级别走势类型”中枢。笔中枢公式列在这里，本次回放默认不另外叠加笔中枢。

向上离开后，已确认回试段实际最低价大于ZG，才属于未返回；等于ZG按触边返回处理。向下镜像。一次离开或一根阳线并不完成这一检查。旧矩形右边缘表示成员覆盖终点，可能早于“确认不返回”的时间。

例：主体区间`[2,8]、[2,7]、[3,7]`，核心为`[3,7]`。离开至12后回试最低7：触边返回；回试最低8：未返回。回试段本身尚未确认时，只记录候选。

## 三、后半本：把画线接到分析

### 走势与级别

一个完整盘整与至少两个同级同向中枢的趋势要分别讨论。书中a、b、c指连接/进出运动，A、B、C指中枢。还未走完时保留当前划分与可能的扩张，不因为想要“a+A+b+B+c”而强行补齐。

时间周期不是自动生成的理论级别。`30m`、`5m`的标签只能说明K线采样周期；严格级别需要完成结构递归证明。书中“不看15分钟/60分钟”“9笔升级”“大周期一笔相当于小周期一段”等适合帮助入门的说法，**本次不写成普遍恒等式或强制软件限制**。

### 背驰与区间套

先指出被比较的两段同级、同向运动及中枢背景，再比较力度。MACD柱面积、幅度、斜率可作辅助证据；两组柱面积一大一小本身不构成严格背驰。

区间套要保留大级别末端的原始起止时间，再查同一区间的小级别走势。小级别出现反转，不自动证明大级别反转；还需检查大级别结构位置、比较对象及更后续的确认。

### 三类买卖点：用于复习的结构条件

| 类型 | 先说明什么 | 还要等什么 | 常见误判 |
| --- | --- | --- | --- |
| 一类 | 前一个同级趋势及其终结运动、同向力度比较 | 更低级别终结/反转证据 | MACD背离直接叫一买 |
| 二类 | 已命名的一类候选、其后第一次反向运动与回试 | 回试的边界/力度及低级别确认 | 任意更高低点都叫二买 |
| 三类 | 已命名中枢、离开段、首次回试段 | 回试不返回且自身获得确认 | 只突破ZG就叫三买 |

卖侧镜像。本书强调二买回试不低于一买；与其他原文解释的边界差异应单独保留。本次工具只练画线与确认时间，**不根据书中仓位举例自动生成交易指令**。

“三买一定赚钱”“走势通常只到c”“理论证明稳定盈利”等叙述不作为本次算法的效果结论。结构定义成立与策略具有收益优势是两个不同的验证问题。

### 结合律与多义性

组件按顺序完整组合，不跳过中间组件，不把两个完整走势的局部任意拼接。相邻笔共享一个连接端点是正常现象，不等于重复使用整段组件。

当前可以存在多种合法划分，后续走势会提供新证据。程序需要版本和撤回记录，不能只留下最终漂亮的历史图；“当前确认”也不等于任何后续输入下都永久不可修订。

## 四、代码怎么用

本次新增入口为`缠论算法/tools/guanpeng_study.py`，复用已有六个引擎模块；没有覆盖原有核心代码。

在工作区根目录运行，只需要Python 3.11+标准库：

```powershell
python "缠论算法/tools/guanpeng_study.py" --output-dir "artifacts/guanpeng-20261110/demo"
```

生成`画线复习.html`、`analysis.json`、`events.jsonl`、`synthetic.csv`、`manifest.json`。双击HTML可以离线拖动逐根截止位置、切换图层、查看对象依据和练习答案。合成序列只是结构教学示例。

真实行情CSV要求至少有`open,high,low,close`列；可提供`closed_at,volume,is_closed`。价格必须有效，时间须递增；多周期研究另需明确带时区的收盘时间。原始K线和包含后的标准区间分层显示。

```powershell
python "缠论算法/tools/guanpeng_study.py" --csv "D:/data/bars.csv" --level 30m --bars 500 --output-dir "artifacts/guanpeng-20261110/my_csv"
```

`--bars 500`表示明确只用前500行，不是最近500行；没有此参数则用全量输入。回放是逐个前缀重算，长历史会较慢。非空输出目录拒绝覆盖，换新目录即可。

### 规则与代码对应

| 对象 | 现有模块/函数 | 本次固定口径 |
| --- | --- | --- |
| 包含 | `chanmodel/structure.py: merge_bars` | 方向合并、来源追踪；开头方向为工程初始化 |
| 分型 | `chanmodel/structure.py: fractals_at` | 高低同时严格比较 |
| 笔 | `chanmodel/structure.py: stroke_check, strokes_at` | `strict`标准K线间隔，反向合法笔确认 |
| 线段 | `chanmodel/segments.py: build_segments` | 特征序列与公开破坏路径补充 |
| 中枢 | `chanmodel/centers.py: build_centers` | 已确认线段实际范围、固定初始核心、离开回试状态 |
| 时间与修订 | `chanmodel/engine.py: ReplayEngine` | 前缀重算，追加事件，保留修订与撤回 |
| 本书练习入口 | `tools/guanpeng_study.py` | 导出回放与来源；不生成买卖信号 |

### 时间字段必须会读

- `start/end`：线画在哪个原始K线位置。
- `basis_at`：当前结构版本依据涉及到哪根输入K线。
- `available_at`：这个版本何时被观测到。
- `confirmed_at`：这个对象版本进入确认状态的观测时间；不是端点时间。
- `revision`：版本号；`events.jsonl`还保留`withdrawn/revised`等事件。

书中没有给出的边界政策和线段实现都已在`manifest.json`中声明。输入哈希、引擎文件哈希、参数与合成/真实来源一并保存。

## 五、闭卷练习（先做，再看答案）

1. `[10,18]`与`[12,20]`是否包含？
2. 已知向下，`[10,18]`与`[12,16]`合并成什么？
3. 两个分型中心标准K线编号为2、5，能按本次严格口径成笔吗？
4. 中心编号2、6的两端分型，完整支撑窗口是哪几根？
5. A→B已合法，B→C刚能构成合法反向笔，哪条确认、哪条仍待确认？
6. 起始三笔仅有一个共同价格，能否按本次约定成候选线段？
7. 两个线段都向上，是否足以认定同级上升趋势？
8. `[2,8]、[2,7]、[3,7]`的ZD、ZG是多少？
9. 向上离开ZG=7后，已确认回试最低价=7，是未返回吗？
10. 高点在第100根，确认依据到第112根才出现，能否在回测中按第100根已确认执行？
11. 三个任意相交的笔，是否自动构成严格递归中枢？
