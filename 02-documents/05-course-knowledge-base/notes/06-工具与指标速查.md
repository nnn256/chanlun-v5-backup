## 2. 网页插件与客户端公式

浏览器插件读取网页图表数据，叠加结构层；通达信和文华WH6的近似公式是独立实现，不是插件源码或客户端移植版。博易大师与MT5的客户端指标也不能直接视作同一程序。

对比一个公式时至少查看：包含处理范围、端点替换、线段近似方法、中枢输入、实时修订以及未来函数/重绘行为。名称中写“缠论”不证明规则一致。

本次已归档官网通达信与WH6公式说明正文，以便检索其近似范围；未安装插件、导入公式或执行下载代码。

## 3. 排查顺序

检查浏览器是否支持、扩展是否启用、是否正确的独立K线页面；等待数据加载；检查图层；确认市场和周期；记录复权及已加载历史；最后再检查结构计算差异。没有矩形可能是输入与成员条件尚不满足，不能一律当安装故障。

官网说明基础图层有免费额度，云快照及回放涉及账户权益。额度和权益以实际产品页面为准，本库不把这类可能变化的信息当固定算法参数。

## 4. 指标公式表

以下为常见定义速查；具体输入、种子值、平滑、缺失值与零分母处理需与目标软件对齐。指标用于辅助观察，不能单独定义缠论买卖点。

| 指标 | 常见算式/对象 | 最容易漏掉的口径 | 来源 |
| --- | --- | --- | --- |
| MA | 最近N期输入的算术平均 | 周期是K线单位；不等于持仓成本 | [MA](https://www.structguide.com/indicators/ma) |
| EMA | `αX+(1-α)EMA前`，`α=2/(N+1)` | 首值与预热长度；不是只看N项 | [MA/EMA](https://www.structguide.com/indicators/ma-vs-ema) |
| MACD | `DIF=EMA短-EMA长`；`DEA=EMA(DIF)`；柱`DIF-DEA` | 柱是否乘2；字段名称与平滑算法 | [MACD](https://www.structguide.com/indicators/macd) |
| BOLL | 中轨MA；上下轨`MA±kσ` | 总体/样本标准差、输入和周期 | [BOLL](https://www.structguide.com/indicators/boll) |
| KDJ | `RSV=100(C-LLV)/(HHV-LLV)`；K/D递推，`J=3K-2D` | 常见递推1/3权重与种子50；J可越界 | [KDJ](https://www.structguide.com/indicators/kdj) |
| RSI | 令U=max(ΔC,0)、D=max(-ΔC,0)，常用`100 RMA(U)/(RMA(U)+RMA(D))` | Wilder/RMA、EMA与简单平均不同 | [RSI](https://www.structguide.com/indicators/rsi) |
| BIAS | `100(C-MA)/MA` | 单位百分比，MA为0需定义 | [BIAS](https://www.structguide.com/indicators/bias) |
| ATR | `TR=max(H-L,abs(H-C前),abs(L-C前))`，ATR平滑TR | 跳空纳入TR；ATR为价格单位 | [ATR](https://www.structguide.com/indicators/atr) |
| CCI | `TP=(H+L+C)/3`，`(TP-MA(TP))/(0.015×MD)` | MD为绝对偏差均值，不是标准差 | [CCI](https://www.structguide.com/indicators/cci) |
| OBV | 按收盘涨跌累加/扣减V，平价通常不变 | 起始常数、平价处理与量单位 | [OBV](https://www.structguide.com/indicators/obv) |
| VOL/MAVOL | 成交量及最近N期量均值 | 股/手/合约、量和额、颜色定义 | [VOL](https://www.structguide.com/indicators/vol) |
| VWAP | 指定起点起`Σ(PV)/ΣV` | 重置起点、逐笔/典型价近似 | [VWAP](https://www.structguide.com/indicators/vwap) |
| DMI/ADX | 高低价增减筛选±DM；平滑后算±DI、DX、ADX | DM并列处理、Wilder种子、ADX不表示方向 | [DMI/ADX](https://www.structguide.com/indicators/dmi-adx) |
| PSY | N期上涨次数/N×100 | 平价是否计分母，初始窗口 | [PSY](https://www.structguide.com/indicators/psy) |
| ROC | `100(C/C前N期-1)` | 分母为0；不是逐期涨跌幅直接相加 | [ROC](https://www.structguide.com/indicators/roc) |
| WR/%R | 正刻度`100(HHV-C)/(HHV-LLV)`，负刻度为其相反数 | 刻度方向、窗口和零振幅 | [WR](https://www.structguide.com/indicators/wr) |

RSI表中RMA表示Wilder递推，平滑权重1/N。DMI常用`+DI=100RMA(+DM)/RMA(TR)`，负向同理；`DX=100abs(+DI--DI)/(+DI+-DI)`，再平滑为ADX。计算中应为零分母制定显式规则。

## 5. 手算与解释边界

收盘10、12、11、13，采用EMA3、EMA5、DEA3，均以首个价格/首个DIF为种子。第二项EMA3=11，EMA5≈10.6667，DIF≈0.3333，DEA≈0.1667，柱≈0.1667。目标软件若柱乘2则约0.3333，两条线不因此翻倍。此例来自网站MACD页的教学设置，不是参数推荐。

BOLL的两倍标准差并不直接提供未来落在区间内95%的保证；ADX高不等于必然上涨；RSI70不等于未来上涨概率70%；红色成交量柱不等于净资金流入。这些是数值含义与交易推断之间的区别。
