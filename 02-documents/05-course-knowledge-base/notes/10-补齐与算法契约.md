## 101课必须明确补入的条件

101课明确讨论了二买低于一买的弱情形。本库前面的“不破一买低点”属于保守研究筛选，不是所有原文情形的必要条件。新版算法提供：

- `second_policy=original_101`：标准回试之外，允许低于/等于原点但力度较弱的研究候选，标注弱回试及所用力度代理。
- `second_policy=conservative`：只保留不破原结构边界的保守筛选，并明确这是策略约束。

不能因为第一候选曾经失效，就从事件记录里删去那次观察。回试分支和新版判断应在实际获得依据的时点新增。

## 知识如何变成算法

| 知识对象 | 新版模块 | 核对方法 |
| --- | --- | --- |
| 包含/方向/价格来源 | `chanmodel/structure.py` | 数值例、等价边界、最早原始来源 |
| 分型/笔 | `chanmodel/structure.py` | 高低双比较、两种计数、不共用、反向笔确认 |
| 线段 | `chanmodel/segments.py` | 无缺口、有缺口第二序列、笔破坏、端点重选 |
| 中枢 | `chanmodel/centers.py` | 实际覆盖范围、固定边界、成员与L0/L1 |
| 背驰/买卖点 | `chanmodel/signals.py` | 命名比较对象、趋势背景、首次回试、101课弱回试 |
| 时间与修订 | `chanmodel/engine.py` | 前缀回放、版本可用时间、历史修订当下记录 |
| 多周期 | `chanmodel/engine.py` | 同一截止时间、实际收盘时间、子区间嵌套 |
| 事后评估 | `chanmodel/evaluate.py` | 事件出现后的下一根开盘，未来只作结果标签 |

完整入口：[算法说明](../../缠论算法/README.md)。高层递归和信号仍标注代理；公开数字算例通过不等于已证明与插件所有输出完全相同，也不等于策略绩效已经验证。
