# Struct Guide画线规则学习笔记

状态：已核对官网规则正文及数字图例说明；本章描述网站公开的插件规则，未执行插件源码或逐图验证实际运行结果。规则日期以本库来源清单保存的2026-11-06快照为准。

来源：[参数](https://www.structguide.com/faq/drawing-rules)、[包含](https://www.structguide.com/concept/containment)、[分型](https://www.structguide.com/concept/fractal)、[笔](https://www.structguide.com/concept/stroke)、[线段](https://www.structguide.com/concept/segment)、[中枢](https://www.structguide.com/concept/central-zone)。

## 1. 输入与面板

输入是当前网页已加载的K线；每个页面、周期分别计算，不自动建立跨周期的结构嵌套。历史范围、复权和报价源不同，结构可能不同。

默认宽松笔、有效分型；分型图层关闭，笔、线段、中枢图层打开，配色红涨绿跌。保存的设置优先。图层开关和颜色只影响显示，笔模式会影响计算。没有单独的包含开关、线段缺口开关或严格/宽松线段模式。

## 2. 包含关系

设相邻区间为`[L1,H1]、[L2,H2]`，若`H1>=H2且L1<=L2`，或反过来成立，进入包含处理。等高、等低、两端全相等都计入。比较高低范围，含影线。

| 输入 | 判断 |
| --- | --- |
| [10,18]与[12,16] | 前项包含后项 |
| [10,18]与[9,19] | 后项包含前项 |
| [10,18]与[12,18] | 等高仍包含 |
| [10,18]与[12,20] | 普通重叠，不包含 |

方向确定后，向上高低都取max，向下高低都取min。

### 方向与顺序

准备合并A、B时，先找A左侧已留下的P：P到A高低都严格抬高，则向上；都严格下降，则向下。未满足时，插件再比最高价，A最高价不低于P取向上，否则向下。

无P的序列开头，比较A、B的高低价均值；右项更高取上、更低取下，均值相等再比收盘，右项收盘不低于左项取上。这是插件的起始处理约定。

逐根读入；包含后合并，回查左侧相邻项；这一轮完成后才继续读新K线。不能用任意分组合并替代该顺序。

### 价格来源

计算序列变短，原始蜡烛不变。高低价分别保存来源；同一组内相同价格取最早来源。标记可能落在合并组较早的原始柱，而非最后一柱。向下合并保留下来的最高价，也不一定是整组合并前的最高价。

## 3. 分型

在连续三个标准区间左、中、右上同时检查高点与低点：

```text
顶：H中>H左 且 H中>H右 且 L中>L左 且 L中>L右
底：H中<H左 且 H中<H右 且 L中<L左 且 L中<L右
```

所有比较严格，等号不通过。标记价取中间项的高点或低点，再映射到该价格的最早原始来源。

全部分型显示通过识别的集合；有效分型显示被当前笔采用的集合，可能包含待确认笔的端点。显示设置不改变笔的计算。

插件没有额外等待参与比较的K线收盘。实时K线变化、包含重组、端点替换都可能使分型标记移动或消失。做收盘后研究时，应另加“右侧K线已闭合”的研究条件，注明它比插件实时行为更保守。

## 4. 笔

两种模式共同要求：异类分型；两端各有完整的三根标准K线；同一笔两端分型组不共用标准K线；顶中心的最高价严格高于底中心最高价；通过所选间隔要求。

注意价格检查的对象：插件比较顶、底两根中心标准K线的最高价，允许区间部分重叠，未额外要求顶中心最低价高于底中心最低价。这是本插件的公开条件，不自动推成所有原著解释共同的规则。

| 模式 | 不含两端的间隔 |
| --- | --- |
| 严格笔 | 两个分型中心标准K线之间至少3根标准K线 |
| 宽松笔 | 两个分型极值来源原始K线之间至少3根原始K线；仍须满足标准分型组不共用 |

严格模式中心编号2与6，中间3、4、5三根，通过；中心2与5只有两根，不通过。完整分型为1—3与5—7时，两组之间的独立标准K线是4。

宽松模式极值来源原始编号10与14，中间11、12、13三根，通过。不能取合并组最后一根编号替代极值来源编号。

相邻两笔A—B与B—C应共用B，这与“一笔两端分型组不能共用标准K线”没有冲突。

### 端点与确认

连续同类分型选更极端者；价格相同保留较早端点。异类且满足全部条件后，先形成候选笔。候选终点可被更极端同类分型替换，再检查能否合法连接。第一笔未确认时，起点也可能重选。

A—B仍合法，且B—C已能构成合法反向笔，A—B得到确认，B—C可仍待确认。无需等B—C自己确认。

确认只描述当次计算。C若受实时K线影响而失去分型条件，B—C确认依据撤回，最近A—B可能退回虚线。仅尾部延伸、原确认依据仍成立时，不把已确认A—B拖长。

## 5. 线段起始

输入为已生成笔序列，尾部笔可能未确认。至少三笔，按第一笔方向检查；前三笔端点区间的共同部分必须有正宽度。

`10→18→12→20`对应[10,18]、[12,18]、[12,20]，共同[12,18]，可形成候选；`10→18→8→10`只有一个共同价10，不通过。

前三笔满足只是起点；后续不要求每笔都始终停留在该重叠区。第一条线段尚未找到时可继续搜索起点，已有确认段后，下一段须从共同端点连续衔接。

## 6. 线段结束：特征序列路径

向上段抽取向下笔的端点范围，找顶分型；向下段抽取向上笔，找底分型。特征元素不是原始行情K线。

包含处理按前置非包含元素与左项的局部方向取值，不能恒定跟随候选段方向。无参照才沿用传入初始方向。第一序列的假设转折点两侧不跨界合并；第二序列正常处理包含。

每次尝试一个候选结束位置，左侧最后标准元素作为F1，右侧取得F2、F3构成窗口。F2极值真实来源决定结束位置。极值来源若变化，要重建相应候选，不能借用错误分界的价格。

### 无缺口

向上段`F1.high>=F2.low`为无缺口；向下段`F1.low<=F2.high`为无缺口。相等归入无缺口。

局部分型成立后，还检查旧段至少三笔、起始三笔重叠、末笔方向、终价与起价方向。通过后可确认，无需额外等待下一笔或第二序列。

例：`10→20→12→25→15→22→13`。反向元素[12,20]、[15,25]、[13,22]形成顶分型，20>=15无缺口。到13时取得依据，旧段结束点仍在25。

### 有缺口

向上段`F1.high<F2.low`，或向下段`F1.low>F2.high`为有缺口。此时第一序列分型成立仍只留候选。

向上旧段转入反向候选，抽向上笔，等第二序列底分型；向下旧段镜像等顶分型。第二序列首次满足条件后保留其确认，但也须检查此前候选是否先被原方向更极端端点打破。

例：第一序列[5,10]、[20,30]、[15,25]，10<20有缺口，30先是候选。其后第二序列[20,25]、[15,24]、[18,27]成底分型，且候选未先失效，才取得结束依据。

## 7. 线段结束：第一反向笔破坏后的成段路径

向上旧段的第一反向向下笔终点不高于旧段较早向上笔顶点，比较的两笔之间至少隔两笔，才满足这里的笔破坏比较。无需跌破旧段的前底。

随后，从候选端点起至少已有三笔，后续向下笔终点严格低于第一反向笔终点；此前向上端点未严格超过候选价，才得到成段确认。向下旧段镜像处理。

例：`10→20→14→25→18`，18<=20已笔破坏；再到22→16，16<18才确认结束在25。若未确认就先到26，25处候选失效。等于18只满足笔破坏相关边界，不满足后续严格越过要求。

## 8. 两路径取舍与历史修订

一条确认另一条等待时用已确认者；两条都确认时选结束位置更早者；都等待时留更早候选；同一位置两条都确认时选特征序列结果。这一排序是网站明确标识的工程约定。

因此即使前面的笔不变，新增数据也可能让更早候选后获确认，进而替换已有线段划分。**实线不意味着之后永远不变。**研究时保存当时输出，不把最终划分回填成历史已知事实。

## 9. 中枢矩形

初始输入是连续三条已确认线段；每段取包含两端在内、覆盖的所有原始K线的实际最高/最低价，不能只用连线端点。

```text
ZG=min(H1,H2,H3)
ZD=max(L1,L2,L3)
只有ZG>ZD才有可绘制的正高度矩形
```

初始成员和实际范围不变时，ZG、ZD固定；后续极值不直接扩大核心边界。

成员还要符合：相邻独立矩形之间保留完整连接段；连接段不重复归两侧；旧框第三构成段不再充当连接段。新框整体高于旧框时检查初始三段“下、上、下”，整体低于时“上、下、上”；没有确定关系时不强指定方向。窗口不合法就后移，不切线段凑数。

### 延伸的L0/L1检查

L0是初始三段之后的已确认越界段；向上看实际最高价越过ZG，向下看最低价越过ZD。L1是紧接其末端的反向已确认线段，不能用待确认段代替。

| 向上L0后，L1实际最低价 | 处理 |
| --- | --- |
| >ZG | 未返回，满足条件后旧框停止延伸 |
| =ZG | 触边按返回 |
| ZD<=最低价<ZG | 进入区间，继续成员与延伸检查 |
| <ZD | 穿过另一边，转为反方向越界检查 |

向下L0以L1最高价对ZD、ZG镜像判断。比较前按小数精度归一化，不能用屏幕四舍五入标签判断等号。

旧框停止后，从L1所在处重新寻找满足全部条件的三段窗口；停止旧框不保证马上有新框。连接段L0不重复计入成员，因此右边缘可以早于停止依据时点。

中枢没有独立确认标签，也不自动合并为更高级别矩形。初始成员、底层线段或原始数据修订后须重算。

## 10. 核对一个差异的顺序

固定数据与设置 → 比原始K线 → 比包含分组及价格来源 → 比分型 → 比笔的模式、端点与状态 → 比线段候选和确认路径 → 比中枢实际范围、成员与停止依据。

每次只改变一个条件。记录当前截止时点与旧输出，比较第一个不同的位置；最后那条线的差异通常来自更早的输入或结构分歧。
