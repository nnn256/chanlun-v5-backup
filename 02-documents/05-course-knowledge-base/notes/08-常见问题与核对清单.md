| 有效分型是不是完全不会变？ | 它是当前被笔采用的显示集合，可含待确认端点。 |

| 两笔共用端点违背不共用规则吗？ | 不违背；不共用检查同一笔的两端分型组。 |
| 三笔一定是一个线段吗？ | 不一定，起始共同区间和后续确认都需检查。 |
| 特征序列的元素是原始K线吗？ | 是从笔取出的区间，可按规则做类似包含处理。 |
| 特征缺口就是行情跳空吗？ | 二者比较对象不同。 |
| 有特征分型就都能立即确认线段？ | 要分缺口情形并检查整体旧段条件。 |
| 笔破坏等于线段结束吗？ | 后面仍需成段或特征序列确认。 |
| 实线能保证以后绝不修订吗？ | 插件当前确认仍可能被实时数据或后到的更早候选改变。 |
| 端点日期就是识别出来的日期吗？ | 常常晚些才取得依据，应分字段保存。 |
| 三条笔重叠就能代替理论中枢吗？ | 必须标明最低层设定或代理口径，不能无条件替代递归定义。 |
| 插件中枢只看线段端点吗？ | 看已确认线段覆盖的全部原始K线实际极值。 |
| ZG/ZD与GG/DD是一组东西吗？ | 核心区间与外围范围不同，还要核对具体公式的成员口径。 |
| 旧框不延伸就必有新框吗？ | 新框另需三段、区间和成员条件。 |
| 插件触边算未返回吗？ | 中枢延伸规则中等号按返回处理。 |
| 日线出现两个矩形就是日线趋势吗？ | 还需结构级别、完成状态与外围范围关系。 |
| MACD金叉是一买吗？ | 指标交叉本身不充分。 |
| 更高低点是二买吗？ | 需一买上下文与首次合格次级别回试。 |
| 越过ZG就是三买吗？ | 还需离开后的首次合格回试与边界/完成条件。 |
| 二买和三买能重合吗？ | 原文21课讨论了相应条件下的重合。 |
| 小级别背驰必然引发大级别转折吗？ | 不能直接推出，参见44课必要条件与后续结构。 |
| 同级别分解能允许盘整+盘整吗？ | 38课明确讨论其特殊分解口径，应与非同级别解释区分。 |
| BOLL两倍标准差等于未来95%保证吗？ | 不能由算式直接得到这种未来概率保证。 |
| 学完理论就等于有盈利策略吗？ | 还需实时识别、成交约束与独立样本检验。 |
| 本库已观看全部视频与原图吗？ | 未逐集观看或逐图审阅，正文归档和主题核对分别标记。 |

## 每次标图的12项核对

1. 有没有明确品种、截止时间、数据源与复权？
2. 有没有把K线周期与结构级别区分？
3. 包含方向、处理顺序和价格来源能否复算？
4. 分型是否同时检查高低点？
5. 笔是否通过全部条件，模式是否明确？
6. 线段的确认路径、候选失效与结束位置是否有证据？
7. 中枢的三个输入是否在所选口径下合格？
8. 核心、外围范围、成员与级别是否混淆？
9. 背驰比较的两段是否同向且结构可比？
10. 买卖点的前序、首次性与回试完成是否明确？
11. 使用的是当时版本，还是后来修订的最终图？
12. 是否记录失效条件、替代解释和下一步观察？
