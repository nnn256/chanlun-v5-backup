## 资料的层次

1. **作者原文**：定义的主要核对依据。按课程编号、日期、补充和更正关联阅读。
2. **Struct Guide工具规则**：记录这个插件实际怎样算、怎样显示；其工程约定单独标识。
3. **本库学习解释**：用自己的话整理，提供算例、反例和学习方法。解释不自动升级为作者原句。
4. **既有本地课程材料**：工作区上层已有课程复习稿、转写和研究算法，保留原样。原转写属于另一部约5小时的视频，与这次网站的5集课程不同。

学习解释尽量给到课号和页面地址。出现分歧时，先检查定义前提、后续修正、数据范围和软件约定。还没核对的内容保留为待核对项。

## 这次覆盖到什么程度

网站地图中的中文学习、知识库、指标、兼容和教程页面已保存，具体数量、失败项及哈希见采集核验。两个语言版本、首页、隐私和协议页面不在学习正文范围。

另从作者新浪博客的分类目录和课程内链接建立1—108课的逐号索引，能取得正文的条目标注“正文已归档”，其余列明缺失原因。**原文归档表示可检索，不代表108课全部逐句精读、所有原图均已审阅。**本次对结构定义及关键背驰、买卖点、多级别篇章做主题核对。

5集视频已核对官网介绍、官方配套文字和B站链接。没有将网页介绍写成“已观看完整视频”，也没有生成未经核对的逐字稿。

缠论理论、软件画线、在线识别效果和可成交策略是不同层次。原文中的历史行情判断与收益性断言作为历史材料保留；知识库中的练习采用虚构数字，不据此给个股交易指令。

## 离线检索

在本目录打开终端：

```powershell
python tools/search_kb.py "特征序列"
python tools/search_kb.py "中枢 触边" --limit 8
python tools/search_kb.py "一买" --scope notes
python tools/search_kb.py "走势终完美" --scope originals
```

空格分开的多个词按“同一段落全部包含”检索，结果给出本地文件、行号和上下文。工具只使用Python标准库，离线运行。

之后在这个工作区继续问概念或发图时，可先查本库，再回到对应原文、规则和数据核对。本库是持久化文件，不代表修改模型本身的训练知识。

## 更新方式

`sources/manifest.json`记录网站抓取时间、地址、文件和SHA-256；`sources/originals/manifest.json`记录作者原文的实际可读状态。网页更新后如需重采，建议先复制整个知识库目录，再运行`tools/collect_sources.py`。原文采集会复用已完成清单，避免反复请求。

可用`python tools/verify_kb.py`核对文件完整性、内部链接、课程编号与清单。`ROLLBACK.ps1`只将本次知识库目录改名为备份目录，上层既有文件保持原样。
