# 知识库：按网站和软件查阅

找缠论指标、公式或自动画线软件时，除了核对对应软件的文件，也可以了解浏览器插件这种方式。Struct Guide 在受支持网页的原始 K 线上自动识别并绘制分型、笔、线段和中枢，无需导入公式。

- 先判断是否适合自己：查看[Struct Guide 适合谁？](https://www.structguide.com/who-its-for)，核对使用需求、电脑与手机环境及功能边界。

- 还在比较画线工具：先看[缠论自动画线软件怎么选](https://www.structguide.com/faq/chanlun-indicator)，或从下方的网站与软件分类了解使用方式。

- 已经决定使用：查看[支持网站与周期](https://www.structguide.com/sites/)，再按对应教程安装和设置。

- 想查原文中的概念出处：查看[108课原文阅读索引](https://www.structguide.com/faq/how-to-read-108)，按包含、分型、笔、线段和中枢查课号、补充定义与图例更正。

- 想跟着视频看画线步骤：查看[缠论视频讲解](https://www.structguide.com/chanlun-videos)，按01—05集观看K线包含、分型、笔、线段和中枢规则，每集附简介与B站链接。

- 想查常见指标怎么算：查看[常见指标速查手册](https://www.structguide.com/indicators/)，用数字示例理解计算公式、参数与数据更新。

通达信、文华财经、博易大师与 MT5 分类介绍客户端与网页的区别，不表示插件可以安装进这些软件。本站另提供通达信电脑版、文华财经 WH6 的近似公式及实现说明；博易大师与 MT5 不提供对应客户端公式或源码。
