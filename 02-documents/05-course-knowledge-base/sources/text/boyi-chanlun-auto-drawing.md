# 博易大师缠论自动画线：指标源码、安装环境与网页方案

找博易大师缠论公式，是希望自动显示笔、线段和中枢，还是需要把指标导入博易大师？若可以另开期货网页查看结构，本页介绍一种无需导入公式的方式。

Struct Guide 在受支持的新浪财经网页 K 线上自动识别并绘制结构。它是浏览器插件，不能安装进博易大师；本站不提供该客户端的缠论公式或源码。 必须使用博易大师原图和数据时，应继续核对相应客户端文件。

## 不导入客户端公式，网页上会显示什么？

Struct Guide 在网页原有 K 线上叠加分型标记、笔与线段的连接线、中枢区间。图层可以分别开关，笔模式可选择严格笔或宽松笔；网页原有的 K 线、均线和成交量保留。

这条路径需要你在新浪财经网页自行打开品种，不会把博易大师的自选或手工画线带过来。先查[新浪财经缠论自动画线支持说明](https://www.structguide.com/sites/sina)，确认可以接受网页数据后，再按本页[网页使用步骤](https://www.structguide.com/boyi-chanlun-auto-drawing#web-path)操作。

## 博易大师的自选和手工画线会带到网页吗？

不会。Struct Guide 不读取博易大师的自选、参数或手工画线，不将其同步到新浪财经网页。你需要在网页中自行打开相应品种，并核对具体合约、周期和数据范围。

同名图表也可能使用不同报价来源或时段。网页上的结构是根据网页输入计算的，不是客户端画线的复制品。

## 在新浪财经期货网页上怎么使用？

- 查看[新浪财经兼容范围](https://www.structguide.com/sites/sina#supported-periods)，核对需要的市场与周期。

- 在受支持浏览器中按[安装说明](https://www.structguide.com/download/)添加扩展，确认已启用。

- 进入新浪财经单品种期货 K 线详情页，等待主图加载。

- 在插件面板中显示或隐藏分型、笔、线段和中枢。

不要在博易大师客户端中寻找插件面板。详细网页入口见[新浪财经缠论画线教程](https://www.structguide.com/tutorial/sina)，分时与“5日”模式排查见该教程的[“安装后不显示”一节](https://www.structguide.com/tutorial/sina#troubleshooting)。

## 常见问题

### 有博易大师缠论指标或主图源码下载吗？

本站没有该类客户端文件。请勿将 Struct Guide 扩展文件导入博易大师；其他来源的公式文件（包括通达信公式）也应先核对博易大师的公式环境是否支持，不能将不同软件的文件视为直接兼容。

### 为什么在博易大师里安装后没有效果？

Struct Guide 没有博易大师客户端安装方式。应在受支持浏览器中确认扩展启用，然后打开已适配网页。

### 为什么某些历史连线补载数据后不同？

应核对该指标是否依赖后续数据、是否补画历史位置，以及输入数据是否改变。不能仅凭最终历史图判断某个位置当时已经显示；本页不对未提供的公式作实现判断。

### 网页插件可以只显示笔或中枢吗？

可以在 Struct Guide 面板中分别控制图层。笔模式也可更换，但这些选项不与博易大师公式参数互通。具体开关操作见[新浪财经缠论画线教程的图层设置](https://www.structguide.com/tutorial/sina#settings)。

### 新浪财经网页加载失败时，插件能读取博易大师的数据吗？

不能。插件不提供另一套行情，也不连接客户端作为替代数据源。应先恢复受支持网页的 K 线加载，再检查图层。
