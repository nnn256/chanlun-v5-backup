# 新浪财经期货缠论画线教程：K线入口、设置与问题排查

Struct Guide 安装到浏览器后，会在新浪财经受支持的网页 K 线上自动绘制结构。 本教程说明从打开正确页面到设置图层的操作顺序。如果尚未确认使用环境，可先看[新浪财经缠论自动画线支持说明](https://www.structguide.com/sites/sina)。

支持桌面版 Chrome、Edge、360 浏览器及安卓手机上的 Edge。原生行情 App、桌面行情客户端及其他手机浏览器不在插件运行范围内。安卓手机也需要在 Edge 内打开网页。

## 1. 插件在哪里下载、怎样启用？

- 打开[安装说明](https://www.structguide.com/download/)，进入对应浏览器的扩展商店。

- 添加 Struct Guide，在浏览器扩展管理页确认已启用。

- 如果图表在安装前已打开，刷新网页后等待 K 线加载。

## 2. 新浪财经期货 K 线从哪里进入？

- 在[新浪财经网页](https://finance.sina.com.cn/)找到需要查看的品种或合约，打开详情页。

- 在图表区域选择 K 线与受支持周期，避免停留在分时或“5日”区间视图。

- 核对页面名称、合约标识和周期，等待主图数据加载后查看 Struct Guide 面板。

受支持的A股、港股、美股详情页同样从独立 K 线视图使用。完整市场、周期及排除范围统一见[新浪财经兼容范围](https://www.structguide.com/sites/sina#supported-periods)。文华财经或博易大师的客户端窗口不是这个网页入口。

## 3. 分型、笔、线段和中枢怎么设置？

图表加载并出现 Struct Guide 控制面板后，在面板中设置图层。无需反复点击浏览器工具栏图标；各操作对应的显示如下。

| 想完成的操作 | 面板中的操作 | 操作后的显示 |
| --- | --- | --- |
| 显示顶底分型标记 | 开启分型图层 | 显示工具已识别的顶底分型标记 |
| 显示笔或线段连接线 | 开启对应图层 | 显示工具已识别的对应连接线 |
| 更换笔模式 | 选择严格笔或宽松笔，等待重新计算 | 按所选模式重新计算，相关结构可能更新 |
| 只查看中枢区间 | 保留中枢图层，隐藏其他结构图层 | 显示已识别的中枢区间，原有 K 线仍保留 |
| 暂时隐藏画线 | 关闭对应图层，需要时再开启 | 隐藏对应图层；重新开启后显示已识别的对应对象 |

原始 K 线、均线和成交量保留。笔和线段用实线表示已确认、虚线表示待确认；中枢没有独立确认状态标签。开关控制显示，不表示每一段数据都会生成相应对象。参数细则统一见[Struct Guide 画线规则与参数总览](https://www.structguide.com/faq/drawing-rules)。

## 4. 切换品种、周期后如何更新？

保持扩展启用即可。插件检测到周期切换后，会先清空并隐藏旧图层，再等待新数据重新计算。切换输入后，新页面的结构以重新计算后的图层为准。品种、周期、复权方式、历史数据补载或笔模式变化都可能影响结果。

待确认端点可能随新 K 线延伸或调整；端点所在时间与工具取得确认依据的时间可能不同。详见[笔的确认与更新规则](https://www.structguide.com/concept/stroke#confirmation)。

## 5. 安装后不显示，怎么排查？

| 现象 | 核对项 | 处理步骤 |
| --- | --- | --- |
| 期货列表没有画线 | 是否进入具体品种详情页 | 打开详情页的独立 K 线主图 |
| 分时或5日视图没有结构 | 是否选择了受支持的 K 线周期 | 切换到兼容表所列周期 |
| 客户端里找不到面板 | 是否误在文华财经或博易大师内查找 | 浏览器打开新浪财经网页；不在客户端安装 |
| 切换合约后图层未更新 | 页面合约标识与数据是否已切换 | 等待新图加载，必要时刷新并记录重现步骤 |
| 面板有显示，但缺少某类结构 | 对应图层与输入数据 | 开启相应图层；识别条件未满足时不会强制画出对象 |

仍有异常时，可暂时停用可能拦截页面脚本的其他扩展，刷新重试。反馈时记录浏览器与版本、插件版本、页面地址、品种、周期、复权方式、笔模式和重现步骤，通过 [structguide@outlook.com](mailto:structguide@outlook.com) 联系。如附截图，发送前请留意截图中是否包含个人账户信息。

## 常见操作问题

### 日线与5日图为什么不能混用？

日线是本工具支持的 K 线周期之一，“5日”行情区间视图不在支持范围内。排查时应记录实际图表模式，而不只记录屏幕上覆盖的天数。

### 安装之后需要反复点击扩展图标吗？

不需要。扩展启用后，对支持页面自动处理。网页没有加载 K 线时，点击工具栏图标不能替代数据加载。

### 能否同时打开证券和期货网页？

可以分别打开受支持的单品种 K 线标签页，每页按自己的数据计算；两种页面仍需分别核对支持周期。

### 为什么客户端同名期货图表与网页结果不同？

先核对具体合约、数据源、时段、周期及历史范围。Struct Guide 不读取客户端数据，也不将客户端图层同步到新浪财经网页。

## 数据与使用范围

插件只处理当前网页已经加载并展示的 K 线，不提供额外行情数据；网站账户权限仍由网站管理。新浪财经仅为兼容性说明，与本产品无隶属或合作关系。
