# 同花顺缠论自动画线怎么设置？插件安装与使用教程

安装并启用 Struct Guide 后，打开受支持的同花顺网页 K 线，结构会自动显示；图层与笔模式在 Struct Guide 控制面板里设置。 本教程按实际操作顺序说明安装、打开图表、设置和排查方法。

如果还在找同花顺缠论指标、公式或源码，请先看[客户端公式与网页插件的区别](https://www.structguide.com/sites/tonghuashun#formula-or-extension)，确认安装环境是否符合你的需求。

## 1. 同花顺自动画线插件在哪里下载？

- 打开 [安装说明](https://www.structguide.com/download/)，选择对应浏览器的扩展商店。

- 添加 Struct Guide，在浏览器扩展管理页确认已启用。

- 如果同花顺图表在安装前已经打开，刷新页面，再等待 K 线加载。

支持桌面版 Chrome、Edge、360 浏览器及安卓手机上的 Edge。请使用安装页提供的商店入口，无需导入指标公式、主图代码或其他脚本。

安卓手机同样需要在浏览器内打开网页；安装扩展后再打开同花顺 App，不会在 App 内出现 Struct Guide 图层。

## 2. 同花顺网页 K 线从哪里打开？

- 在浏览器中打开[同花顺网页](https://10jqka.com.cn/)，查找你要查看的品种或板块并进入详情页。

- 找到独立 K 线主图，选择受支持的周期。

- 等待 K 线加载，再检查 Struct Guide 控制面板和结构图层。

同花顺首页、自选列表及没有独立 K 线主图的汇总页不用于绘图。完整市场与周期表统一维护在[同花顺兼容范围](https://www.structguide.com/sites/tonghuashun#supported-periods)；请逐项核对，不把网页自身可选的全部周期视为插件已支持。

## 3. 分型、笔、线段和中枢怎么设置？

在 Struct Guide 控制面板中分别显示或隐藏分型、笔、线段、中枢。无需手动点击浏览器工具栏图标触发绘制，也无需逐根连接图中的端点。

## 4. 切换品种、周期后要重新打开插件吗？

保持扩展启用即可。切换品种、周期或复权方式后，先等待新图表加载，Struct Guide 会按新的输入重新计算。切换输入后，新页面的结构以重新计算后的图层为准。

每个受支持的标签页依据各自页面数据独立计算。比较两个页面时，应核对品种、周期、复权方式、历史范围和笔模式，不能只比较连接线的外观。

## 5. 安装后不显示画线，怎么排查？

先区分“控制面板没有出现”和“面板出现但没有某类画线”，再按下面的顺序检查。

| 看到的现象 | 先检查什么 | 下一步操作 |
| --- | --- | --- |
| 没有控制面板 | 是否在支持的浏览器内；扩展是否启用 | 启用扩展并刷新同花顺网页，不在客户端或 App 内查找面板 |
| 面板出现，但没有结构图层 | 页面、市场和周期是否受支持；K 线是否加载 | 对照兼容表，等待 K 线主图加载完成后重试 |
| 只有某类画线没有显示 | 对应图层是否开启 | 开启该图层；开启不等于每份数据都满足其识别条件 |
| 切换周期后仍像旧图表 | 新图表是否加载完成 | 等待加载，必要时刷新；记录切换前后的周期以便排查 |
| 最右侧虚线端点发生变化 | 是否仍为待确认对象；数据或参数是否改变 | 对照确认状态说明，区分正常重算与显示异常 |

上述检查后仍未显示，可以暂时停用可能拦截页面脚本的其他扩展，刷新页面重试。网络加载失败或同花顺页面变化也可能影响显示。

需要反馈时，请整理浏览器名称与版本、Struct Guide 版本、页面地址、品种、周期、复权方式、笔模式、已开启图层，以及重现问题的步骤。可以通过 [structguide@outlook.com](mailto:structguide@outlook.com) 反馈工具显示问题。如附截图，发送前请留意截图中是否包含个人账户信息。

## 常见操作问题

### 设置入口在同花顺公式编辑器里吗？

不在。Struct Guide 的图层与笔模式在网页上的插件控制面板里设置，不需要打开同花顺客户端的公式编辑器。

### 为什么开启中枢后，某一段图表没有矩形？

显示开关只决定是否展示工具已经识别的对象，不会强制生成区间。先核对图层和输入数据；仍有疑问时记录设置与页面信息，按上面的排查方式反馈。不要仅因开关已开启就认定每段图表都应有中枢。

### 为什么最后一笔会变，实线和虚线怎么区分？

待确认端点可能随新 K 线延伸或调整。网页补载、修订历史数据或更换笔模式也可能触发重算；端点所在时间与确认依据出现的时间可能不同。详见[笔的确认与更新规则](https://www.structguide.com/concept/stroke#confirmation)。

### 同花顺账户和 Struct Guide 账户是同一个吗？

不是同一账户。网页数据的访问权限由同花顺管理；Struct Guide 的账户、绘制额度及会员功能按插件内页面说明执行，不替代同花顺账户权限。

## 使用范围

Struct Guide 只处理当前网页已经加载并展示的 K 线，不提供行情数据，也不读取或同步同花顺客户端的图表。安装入口及兼容范围分别见[安装说明](https://www.structguide.com/download/)和[同花顺缠论自动画线支持说明](https://www.structguide.com/sites/tonghuashun)。
