# Struct Guide 支持的网站与K线周期

本页说明 Struct Guide 的网页与浏览器兼容范围。安装前先核对网站、具体图表页面和周期。

画线规则公开： 包含处理、分型、笔、线段和中枢怎样计算，见[Struct Guide 画线规则与参数总览](https://www.structguide.com/faq/drawing-rules)。

支持桌面版 Chrome、Edge、360 浏览器及安卓手机上的 Edge。其他手机浏览器、原生行情 App 和桌面行情客户端不在插件运行范围内。

## 图表页面与数据要求

支持 tradingview.com 的 Full Chart 完整图表页。

moomoo 的“5日”是区间视图，不是 K 线周期。未列出的页面、市场和周期不应默认已支持；第三方网站改版、数据权限和图表加载状态可能影响显示。

插件只处理当前网页已经加载并展示的 K 线，不提供行情数据，不读取其他客户端图表，也不把客户端数据、参数或画线同步到网页。不同报价来源、图表时段、复权方式和历史范围可能产生不同结构。

## 支持市场和周期

| 网站 | 支持市场 | 支持周期 |
| --- | --- | --- |
| TradingView | 全球市场、外汇 | 取决于当前图表可展示的数据 |
| 同花顺 | A股、港股、概念板块、行业板块、地域板块、指数 | A股：1分、15分、30分、60分、120分、日线、周线、月线、季线、年线；港股、板块及指数：日线、周线、月线 |
| 东方财富 | A股个股页、概念版个股页、指数 | 5分、15分、30分、60分、日线、周线、月线 |
| 雪球 | A股、港股、美股 | 1分、5分、15分、30分、60分、120分、日线、周线、月线、季线、年线 |
| 新浪财经 | A股、港股、美股、期货 | 5分、15分、30分、60分、日线、周线、月线、年线 |
| moomoo | 美股、港股、加拿大、日本、澳洲、新加坡、马来西亚、沪深 | 日线、周线、月线、季线、年线 |
