# 缠论自动画线软件怎么选：指标公式、网页插件与兼容范围

找缠论指标、自动画线软件或公式源码，是想让 K 线上自动显示笔、线段和中枢，还是需要编辑一份能在指定软件内运行的代码？先分清这两种需求，再依次核对运行环境、显示结果与费用。

Struct Guide 提供浏览器插件这种方式：安装后，在受支持网页的原始 K 线上自动识别并绘制分型、笔、线段和中枢，无需编写或导入公式。 它不安装进通达信等客户端，也不是 TradingView 的 Pine 指标。

想先了解是否收费，可直接看[免费画线与 VIP 权益的区别](https://www.structguide.com/faq/chanlun-indicator#free-and-vip)；未购买 VIP 也可在相应绘制额度内使用四类基础图层。

## 想自动看结构，还是需要公式源码？

| 你想完成的事 | 如何选择使用路径 |
| --- | --- |
| 在 K 线上自动显示笔、线段和中枢 | 如果可使用受支持网页，可以了解 Struct Guide 的图层；无需先找源码 |
| 在指定客户端内编辑或导入公式 | 核对该客户端的公式环境、文件与使用授权；通达信电脑版可查看本站的近似实现 |
| 保留客户端的报价、时段与历史数据 | 继续核对对应客户端方案；插件不把客户端数据搬到网页 |
| 在手机上查看结构 | 区分安卓 Edge 网页与原生行情 App；本插件使用前者 |

本站不提供第三方或网络流传版本的通达信缠论公式文件；本站自行编写的一份近似实现及其说明，见[通达信近似缠论公式下载](https://www.structguide.com/faq/tongdaxin-approx-chanlun-formula)。该公式不支持通达信手机版。

### 浏览器插件画出来是什么样？

Struct Guide 在网页原图上增加分型标记、笔与线段的连接线、中枢区间，保留 K 线、均线与成交量。四类图层可分别开关，笔模式可选择严格笔或宽松笔。登录后可以保存结构快照并添加备注，结构回放另有试用与会员权限安排，见[免费与付费说明](https://www.structguide.com/faq/chanlun-indicator#free-and-vip)。

这类图层由 Struct Guide 提供，不表示行情网站自身提供相同功能。可先看[分型、笔、线段和中枢的逐层显示图解](https://www.structguide.com/chanlun-auto-drawing#layer-walkthrough)，具体功能见[缠论自动画线插件介绍](https://www.structguide.com/chanlun-auto-drawing)，使用位置按下方网站列表选择。

## 手机版缠论画线工具与电脑端有什么区别？

Struct Guide 支持桌面版 Chrome、Edge、360 浏览器及安卓手机上的 Edge，但使用位置始终是已适配的网页 K 线。手机行情 App 内的指标与浏览器扩展是两种环境，不能因为网页能运行就推定 App 内也能使用。

需要在手机版通达信中导入公式时，应单独核对客户端编辑入口与函数支持，不使用浏览器扩展的安装步骤。

## Struct Guide 的使用边界

插件处理当前网页已经展示的数据，在原图叠加图层。它不提供行情数据，不替换客户端功能，也不执行交易。若必须使用某个客户端的原图与数据，网页插件不能满足这项要求；能够接受网页输入时，再继续核对画线方式与会员权益。

## 比较显示结果时记录什么

运行环境符合需求后，再核对工具怎样画线，以及不同输入和设置会怎样影响显示。

如果你找“笔的划分图解”“线段结束点判断”或“中枢画线公式”，是为了核对软件为什么这样画，可以从[Struct Guide 画线规则与参数总览](https://www.structguide.com/faq/drawing-rules)进入对应小节。那里说明本工具的端点条件、确认过程和区间计算，不提供客户端公式下载。

比较前先固定品种、周期、复权方式、数据来源和已加载的历史范围，再记录软件版本与参数。不同数据源或设置下的图形差异，不能只归因于绘图功能。

如果需要了解 Struct Guide 的实线、虚线和更新行为，请查看[笔的确认与更新规则](https://www.structguide.com/concept/stroke#confirmation)及其他对象细则。知识库不重复列出计算阈值。

### 为什么不同缠论软件画出的笔、线段和中枢不一样？

先定位最早出现差异的对象，再核对依赖它的后续结构。例如笔的端点已经不同，就先检查输入、包含处理和笔模式，不直接从中枢矩形倒推原因。下表只给出核对顺序，具体条件由各规则页维护。

| 顺序 | 两边应记录和对照的内容 | Struct Guide 的核对入口 |
| --- | --- | --- |
| 数据 | 品种代码、报价来源、周期、时段、复权和历史范围是否一致 | 通达信对照页的跨工具核对记录表，这些记录项也适用于其他工具 |
| 包含处理 | 是否先合并 K 线，标记映射到哪根原始 K 线 | K线包含关系详解 |
| 笔模式 | 比较标准 K 线还是原始 K 线间隔，采用哪些端点条件 | 严格笔与宽松笔 |
| 线段确认 | 如何取特征序列、处理缺口和选择结束点 | 特征序列与确认路径 |
| 中枢成员 | 使用哪些已确认线段，取实际区间还是只取连线端点 | 中枢输入与区间公式 · 成员选择 |
| 显示时点 | 比较的是待确认状态，还是取得后续确认依据后的画面 | 结构回放核对方法 |

另一款工具的规则需按其具体版本和文件说明核对。仅凭名称含“缠论”或显示了相同图层，不能推定实现相同；画线不同本身也不足以判断哪一款更正确。缺少输入或规则信息时，应保留未能确定的项目。

## 缠论自动画线可以免费用吗？免费与付费有什么区别？

Struct Guide 的分型、笔、线段和中枢画线不要求先购买 VIP。 未登录的游客和登录后的免费会员，都可在各自的每日绘制额度内使用这些图层。免费使用不等于所有功能、容量和使用期限都不受限制。

| 功能或限制 | 游客（未登录） | 免费会员（已登录） | VIP会员（有效期内） |
| --- | --- | --- | --- |
| 分型、笔、线段、中枢 | 可用，受游客每日绘制额度限制 | 可用，受免费会员每日绘制额度限制 | 可用，每日绘制品种数不限 |
| 云端结构快照与结构库 | 不可用，需先登录 | 可用，按免费会员容量与期限保存 | 可用，容量更大、查看与保存期限更长 |
| 结构回放 | 不可用，需先登录 | 可按试用安排使用，非永久开放 | 会员有效期内可用 |
| 支持的网站、页面与周期 | 按同一支持列表核对 | 按同一支持列表核对 | 按同一支持列表核对 |

每日品种数、快照张数、在线查看与保存天数集中列在[用户协议的会员权益表](https://www.structguide.com/terms#membership-benefits)，实际生效的权益以插件内“会员功能对比”为准。安装前先核对[支持网站与周期](https://www.structguide.com/sites/)，用免费额度确认自己的网页和使用方式，再按所需容量与功能决定是否购买。

### 付费后会增加哪些内容？

VIP 提供相应的绘制额度、快照容量、使用期限与回放权限；基础四类图层并非 VIP 专属。付费不会增加行情数据、解锁行情网站的账户权限，也不会使未适配的网页或客户端变得可用。识别与绘制条件见[Struct Guide 画线规则与参数总览](https://www.structguide.com/faq/drawing-rules)。

### 免费回放试用从什么时候开始？

登录后首次成功使用结构回放时开始计时；开通或持有 VIP 不会暂停或重置试用期。VIP 到期后是否适用试用或宽限期，取决于此前是否使用过回放；试用、宽限期与到期处理详见[用户协议的回放安排](https://www.structguide.com/terms#replay-expiry)。回放可用不等于绘制额度也升级为 VIP 额度。

### VIP 到期后，已经保存的快照会马上失效吗？

不会仅因 VIP 到期就重置已有快照的期限。每张快照按服务端创建记录时确定的在线查看、保存与下载期限处理；之后的会员等级变化或续费不会缩短或延长原期限。到期后新保存的快照按免费会员期限执行。

在线查看与保存、下载是两种期限：在线查看期限届满后，不再提供图片在线查看或备注修改，但在保存期限内仍可查看元数据和下载；保存期限届满后，访问与下载停止，并进入清理流程。具体见[隐私政策的快照保存说明](https://www.structguide.com/privacy#snapshot-retention)。

### VIP 价格在哪里看，会自动续费吗？

购买前在插件会员入口查看价格、有效期和对应权益。会员通过兑换码开通，自兑换成功之日起算；现行方式不提供自动续费，到期不会自动扣款。计费、续费与退款条件见[用户协议](https://www.structguide.com/terms)。

## 常见选型问题

### 找缠论指标，是不是一定要下载源码？

取决于运行环境。使用 Struct Guide 网页插件不需要导入源码；需要修改客户端公式或 Pine 指标时，应核对相应文件是否提供可编辑源码，两者不能混用。

### 能显示同样的四类图层，结果就应该相同吗？

不一定。数据来源、历史范围、参数与实现方式都可能不同。先核对输入和显示状态，再对照具体规则；不把图层名称一致当作算法一致。

### 安装前应该先看价格还是兼容范围？

先核对浏览器、网页、市场与周期是否符合使用要求，再按上方[免费画线与 VIP 权益的区别](https://www.structguide.com/faq/chanlun-indicator#free-and-vip)确认功能范围，并查看插件内的权益和价格。费用不会改变某个客户端或网页是否被适配。
