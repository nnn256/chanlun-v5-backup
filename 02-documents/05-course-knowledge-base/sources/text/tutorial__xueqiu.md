# 雪球缠论插件怎么安装和设置？K线入口与不显示排查

Struct Guide 安装到浏览器后，会在雪球受支持的网页 K 线上自动绘制结构。 本教程说明从打开正确页面到设置图层的操作顺序。如果尚未确认使用环境，可先看[雪球缠论自动画线支持说明](https://www.structguide.com/sites/xueqiu)。

支持桌面版 Chrome、Edge、360 浏览器及安卓手机上的 Edge。原生行情 App、桌面行情客户端及其他手机浏览器不在插件运行范围内。安卓手机也需要在 Edge 内打开网页。

## 1. 雪球缠论插件在哪里下载、怎样安装？

- 打开[安装说明](https://www.structguide.com/download/)，进入对应浏览器的扩展商店。

- 添加 Struct Guide，在浏览器扩展管理页确认已启用。

- 如果图表在安装前已打开，刷新网页后等待 K 线加载。

## 2. 在雪球网页打开 K 线详情页

- 在[雪球网页](https://xueqiu.com/)查找所需品种，进入具体详情页。

- 切换到 K 线视图，选择受支持的周期；不要停留在信息流、自选列表或排行页。

- 等待 K 线加载，再检查 Struct Guide 面板。

支持A股、港股、美股的对应网页，完整周期列表见[雪球兼容范围](https://www.structguide.com/sites/xueqiu#supported-periods)。访问某些数据时，仍需满足雪球自身的账户权限要求。

## 3. 分型、笔、线段和中枢怎么设置？

图表加载并出现 Struct Guide 控制面板后，在面板中设置图层。无需反复点击浏览器工具栏图标；各操作对应的显示如下。

| 想完成的操作 | 面板中的操作 | 操作后的显示 |
| --- | --- | --- |
| 显示顶底分型标记 | 开启分型图层 | 显示工具已识别的顶底分型标记 |
| 在雪球网页自动画笔 | 开启“笔”图层 | 显示工具已识别的笔连接线 |
| 同时显示线段 | 继续开启“线段”图层 | 笔与线段叠加显示，也可单独隐藏其中一层 |
| 更换笔模式 | 选择严格笔或宽松笔，等待重新计算 | 按所选模式重新计算，相关结构可能更新 |
| 只查看中枢区间 | 保留中枢图层，隐藏其他结构图层 | 显示已识别的中枢区间，原有 K 线仍保留 |
| 暂时隐藏画线 | 关闭对应图层，需要时再开启 | 隐藏对应图层；重新开启后显示已识别的对应对象 |

原始 K 线、均线和成交量保留。笔和线段用实线表示已确认、虚线表示待确认；中枢没有独立确认状态标签。开关控制显示，不表示每一段数据都会生成相应对象。参数细则统一见[Struct Guide 画线规则与参数总览](https://www.structguide.com/faq/drawing-rules)。

## 4. 切换品种、周期后如何更新？

保持扩展启用，等待新图表加载，插件按新的输入重新计算。品种、周期、复权方式、历史数据补载或笔模式变化都可能影响结果。切换输入后，新页面的结构以重新计算后的图层为准。

待确认端点可能随新 K 线延伸或调整；端点所在时间与工具取得确认依据的时间可能不同。详见[笔的确认与更新规则](https://www.structguide.com/concept/stroke#confirmation)。

## 5. 安装后不显示，怎么排查？

| 现象 | 核对项 | 处理步骤 |
| --- | --- | --- |
| 自选列表没有画线 | 是否仍停留在列表 | 进入单品种详情页的 K 线视图 |
| 打开的是雪球 App | 是否在浏览器中运行 | 改用受支持浏览器中的网页；扩展不能装进 App |
| 详情页没有面板 | 扩展是否启用，K 线主图是否加载 | 在扩展管理页检查，再刷新网页 |
| 更换品种后仍像旧图 | 新图表是否加载完成 | 等待加载并核对品种、周期，必要时刷新 |
| 面板有显示，但缺少某类结构 | 对应图层与输入数据 | 开启相应图层；识别条件未满足时不会强制画出对象 |

仍有异常时，可暂时停用可能拦截页面脚本的其他扩展，刷新重试。反馈时记录浏览器与版本、插件版本、页面地址、品种、周期、复权方式、笔模式和重现步骤，通过 [structguide@outlook.com](mailto:structguide@outlook.com) 联系。如附截图，发送前请留意截图中是否包含个人账户信息。

## 常见操作问题

### 可以在雪球网页上只显示中枢吗？

在 Struct Guide 面板中保留中枢图层，隐藏其他结构图层即可。它改变的是显示选项，不会强制生成区间或修改网页数据。

### 如何恢复暂时隐藏的结构线？

重新开启对应图层即可，无需卸载重装。若仍未显示，检查页面和周期是否受支持以及数据是否已经加载。

### 同时打开多个雪球标签页会共用画线吗？

每个受支持的标签页按各自页面数据计算，不把另一品种的图层当作本页结果。核对时应同时记录品种和周期。

### BK代码列表里的页面都能画线吗？

[板块代码列表](https://www.structguide.com/sites/xueqiu/boards)用于查找代码与名称，不能代替插件兼容表。能打开某个网页，不等于该网页的图表已适配。
