中枢的延伸、新生与扩展

区分中枢的三种演化，并判断当前中枢处于哪种状态。

上一课的中枢是理想状态：三段重叠，干净利落。真实走势里几乎从不这样。

三段之后走势会继续，这时候中枢会怎么变？有三种可能， 它们的名字很像但含义完全不同。

延伸

中枢形成后，后续走势仍然在 ZG–ZD 区间内来回，中枢的区间不变，只是时间变长。

这是最常见的情况。一个中枢延伸到七段、九段、十几段都很正常。

关键点：延伸不改变 ZG 和 ZD。中枢的区间在最初三段就定死了， 后面的段只要还在这个区间里活动，就都算这个中枢的一部分。

怎么判断延伸结束

当某一段完全离开了 ZG–ZD 区间且不再回来，延伸结束。 这一段就是中枢的离开段。

「不再回来」的判定需要后续走势确认——又是一个未定状态。

新生

走势离开原中枢后，在新的价格区域形成了一个全新的中枢。

新中枢和原中枢的区间不重叠（或者说，它是独立的一个中枢）。

新生是趋势的标志。一个向上趋势就是「中枢 → 上涨 → 更高位置的新中枢 → 上涨 → ……」 这样一级一级往上走。

判断新生要注意：新中枢必须自己满足中枢的定义（三段重叠）， 不能因为「价格涨上去震荡了一下」就认定新中枢。

扩展

这是最容易和延伸混淆的一个。

扩展指的是：两个原本独立的中枢，因为后续走势的关系， 在更高级别上被合并看待。

具体场景：形成中枢 A，走势离开形成中枢 B，然后走势又回到了 A 的区间。 这时候 A 和 B 之间的关系变得暧昧——它们可能一起构成一个更大级别的中枢。

扩展是级别升级的入口

扩展之所以重要，是因为它是中枢升级的机制： 若干个同级别中枢在更高级别上合并成一个中枢，级别就上升了一层。

而中枢升级的判定标准，恰恰是原文里表述最松的部分之一。 不同流派对「几个中枢、什么条件下算升级」的看法不一致。

本站算法采用保守口径：只在明确满足重叠条件时才判定升级。 这意味着我们可能会低估级别，但不会虚报。

三者的区分

用一张表理清：

中枢区间位置意味着
延伸不变原地盘整在继续
新生新的区间移动到别处趋势在推进
扩展合并成更大区间覆盖原来几个级别在升高

一句话记法：延伸是原地不动，新生是搬家，扩展是把几个房子打通成一个大的。

图上的每个框都是一个中枢。观察它们的宽度—— 宽的框说明中枢延伸了很多段，窄的说明只有三段就走了。

再打开「走势类型」层，看中枢和分段边界的关系： 你会发现分段边界总是落在中枢之间，而不是中枢内部。 这不是巧合，是走势分类的定义决定的（下一课）。

为什么这三个概念重要

因为走势的分类完全依赖中枢的数量和排列：

  • 一个中枢（无论延伸多久）→ 盘整
  • 两个及以上同向排列的中枢 → 趋势

如果你把延伸误判成新生，就会把一个盘整数成两个中枢， 从而错误地认定这是趋势。反过来把新生误判成延伸，会漏掉趋势。

所以这三个概念不是学术区分，是直接影响结论的判定。

实操上的建议

遇到拿不准的情况，问自己一个问题： 当前这段走势的价格，还在原中枢的 ZG–ZD 区间内吗？

  • 在 → 延伸
  • 不在，且在别处形成了新的三段重叠 → 新生
  • 不在，但后来又回到了原区间 → 可能是扩展，需要看更高级别

这个问题能解决八成的情况。

这一课的要点

  • 延伸：区间不变，原地震荡继续，最常见
  • 新生：在新的价格区域形成独立的新中枢，趋势的标志
  • 扩展：原本独立的中枢在更高级别被合并，级别升级的入口
  • 中枢升级的判定是原文里表述最松的部分之一，本站采用保守口径
  • 三者混淆会直接导致盘整/趋势判断错误
