# 多级别联立

又称 级别联立

同时观察多个级别的结构状态，用高级别定方向、低级别定位置。

单一[级别](https://chanlunzhan.com/glossary/jibie)的分析总会遇到边界问题：本级别的一[笔](https://chanlunzhan.com/glossary/bi)在[次级别](https://chanlunzhan.com/glossary/cijibie)可能是一个完整的[趋势](https://chanlunzhan.com/glossary/qushi)。多级别联立就是同时跟踪几个级别的结构，看它们的状态如何相互印证或矛盾。

典型用法是高级别确定当下处于什么[走势类型](https://chanlunzhan.com/glossary/zoushileixing)、走到了哪个位置，低级别确定这个位置的精确边界。[区间套](https://chanlunzhan.com/glossary/qujiantao)就是这个思路的极致形式。
