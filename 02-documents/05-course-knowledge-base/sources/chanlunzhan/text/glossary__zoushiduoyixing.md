# 走势多义性

又称 多义性

同一段走势在不同的分解方式下可以归为不同的走势类型。

第 33 课讨论的问题：当[中枢](https://chanlunzhan.com/glossary/zhongshu)发生扩展、或者延伸段数达到升级条件时，同一段行情既可以看成一个大[级别](https://chanlunzhan.com/glossary/jibie)中枢，也可以看成两个小级别中枢加上连接。两种看法都符合定义。

这不是理论的缺陷，而是走势本身的性质。实践中的处理是选定一种分解并坚持下去，同时知道另一种分解存在。本站的算法在扩展关系处选择不合并，把重叠留给上一级[递归](https://chanlunzhan.com/glossary/diguijibie)——这是一个确定性选择，不是唯一正确答案。

这个概念属于 [阶段 7·递归与联立](https://chanlunzhan.com/learn/recursion)。把前七阶接起来。级别递归、多级别联立、区间套，以及走势分解的完全分类。
