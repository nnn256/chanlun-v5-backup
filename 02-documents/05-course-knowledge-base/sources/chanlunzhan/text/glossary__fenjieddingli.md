# 分解定理

又称 走势分解定理

任何走势都可以分解成同方向的连续走势类型，或者上下方向交替的连续走势类型。

第 17 课给出的分解定理保证了[走势分解](https://chanlunzhan.com/glossary/zoushifenjie)的可行性。它的一个直接推论是：如果一段走势中没有形成[中枢](https://chanlunzhan.com/glossary/zhongshu)，那么这段走势的方向保持不变。

算法实现上，这条定理决定了在寻找中枢失败时应该跳几段继续找——跳两段可以保持段序的奇偶性，从而与走势方向一致。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
