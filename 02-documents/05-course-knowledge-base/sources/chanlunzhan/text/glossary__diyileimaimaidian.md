# 第一类买卖点

又称 一买、一卖、第一类买点、第一类卖点

趋势背驰所在的位置。下跌趋势背驰是第一类买点，上涨趋势背驰是第一类卖点。

第一类买点出现在下跌[趋势](https://chanlunzhan.com/glossary/qushi)的[背驰](https://chanlunzhan.com/glossary/beichi)处：至少两个依次下移的[中枢](https://chanlunzhan.com/glossary/zhongshu)之后，最后一段创出新低但[力度](https://chanlunzhan.com/glossary/lidu)不足。第一类卖点对称。

判据链条是：构成趋势 → [离开段](https://chanlunzhan.com/glossary/lijinzoushi)创新极值 → 中枢内[黄白线回拉](https://chanlunzhan.com/glossary/huilalingzhou)零轴 → 离开段力度小于[进入段](https://chanlunzhan.com/glossary/jinruduan)。四个条件缺一不可，这也是为什么真正的一类[买卖点](https://chanlunzhan.com/glossary/sanleimaimaidian)在图上并不多见。

系统学习

这个概念属于 [阶段 6·三类买卖点](https://chanlunzhan.com/learn/maimaidian)。只讲结构定义，不讲怎么交易。一二三类买卖点在缠论里首先是走势分类的产物，不是操作信号。
