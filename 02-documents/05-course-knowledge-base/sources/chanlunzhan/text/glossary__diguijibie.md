# 级别递归

又称 递归、逐级上推

线段构成最低级别中枢，中枢构成走势类型，走势类型再作为次级别单元构成更高级别中枢。

第 35 课给出的上推链条是：[线段](https://chanlunzhan.com/glossary/xianduan) → 最低[级别](https://chanlunzhan.com/glossary/jibie)[中枢](https://chanlunzhan.com/glossary/zhongshu) → [走势类型](https://chanlunzhan.com/glossary/zoushileixing) → 把走势类型当作[次级别](https://chanlunzhan.com/glossary/cijibie)单元 → 高一级中枢 → 高一级走势类型 → 继续上推，直到单元不足或不再成枢。

实践中会发现，日线上 800 根 [K 线](https://chanlunzhan.com/glossary/kline)通常只够推出一级结构。这不是算法的问题，而是级别递归本身就需要极长的历史才能显现——这也是为什么[多级别联立](https://chanlunzhan.com/glossary/duojibielianli)分析在实盘中通常要跨[周期](https://chanlunzhan.com/glossary/zhouqi)做，而不是在单一周期里硬推。

系统学习

这个概念属于 [阶段 7·递归与联立](https://chanlunzhan.com/learn/recursion)。把前七阶接起来。级别递归、多级别联立、区间套，以及走势分解的完全分类。
