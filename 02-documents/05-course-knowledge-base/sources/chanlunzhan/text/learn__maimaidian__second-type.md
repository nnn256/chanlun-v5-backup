# 第二类买卖点

在图上标出第二类买卖点，说清它与一买的结构关系。

[一买](https://chanlunzhan.com/glossary/diyileimaimaidian)是[趋势](https://chanlunzhan.com/glossary/qushi)结束的位置。[二买](https://chanlunzhan.com/glossary/dierleimaimaidian)是趋势结束被验证的位置。

## 定义

第二类买点：第一类买点之后，走出一段向上走势，
然后回抽形成的低点——这个低点不创新低（不低于一买）。

第二类卖点：对称，一卖之后反弹的高点不创新高。

## 「多一次确认」是什么意思

一买成立时，我们知道的是：下跌趋势因[背驰](https://chanlunzhan.com/glossary/beichi)而结束。

但「趋势结束」只意味着这个下跌结构走完了，
不意味着后面就一定向上——它也可能进入长时间的[盘整](https://chanlunzhan.com/glossary/panzheng)，
甚至在更大[级别](https://chanlunzhan.com/glossary/jibie)上继续下跌。

二买提供的额外信息是：价格离开一买之后回来测试，没有跌破。

这是一个实际发生的事实，不是推论。它验证了一买这个位置确实起到了作用。

结构上的严格说法

一买后向上的那一段，至少是[次级别](https://chanlunzhan.com/glossary/cijibie)的一段走势。
回抽如果不创新低，说明这段向上走势没有被完全否定。

从结构角度看，此时至少形成了「低点抬高」的雏形——
这是构成新[中枢](https://chanlunzhan.com/glossary/zhongshu)或新趋势的必要条件之一。

## 一买和二买的关系

|  | 一买 | 二买 |
| --- | --- | --- |
| 依据 | 趋势背驰 | 回抽不创新低 |
| 位置 | 更低 | 更高（通常） |
| 确认速度 | 慢（要等离开段走完） | 相对快 |
| 证据强度 | 推论 | 事实验证 |

「位置更高」加了「通常」两个字，因为存在二买低于一买的特殊情况——
在某些结构里回抽的低点可以略低但仍不算创新低（取决于口径）。
本站算法用严格不低于一买的判定。

## 没有一买也能有二买吗

按严格定义，二买依赖一买——它的定义里直接引用了一买的位置。

但实操中经常遇到一种情况：你在图上看到一次「回抽不创新低」，
但往前找不到清晰的一买（可能是因为趋势的背驰不明显，
或者级别判定不清）。

这时候的处理方式各家不同：

- 严格派：没有一买就没有二买，这个位置不做标记

- 宽松派：只要结构上是「下跌 → 反弹 → 回抽不破」，就标为二买

本站的处理

本站算法要求先识别出一买，二买必须在一买之后。
这会漏掉一些宽松派会标记的位置，但保证了标记的结构含义是明确的。

这又是一处[口径分歧](https://chanlunzhan.com/glossary/koujingfenqi)。看到不同工具标的[买卖点](https://chanlunzhan.com/glossary/sanleimaimaidian)位置不一样，
先想想是不是这个原因。

## 级别的连带关系

二买的级别继承自一买。日线级别一买之后的二买，就是日线级别的二买。

但有个细节：判断「回抽不创新低」时，回抽本身是次级别的走势。
所以观察二买实际上是在两个级别上同时进行的——
本级别看位置关系，次级别看回抽的结构是否走完。

这个「两个级别同时看」的操作，是阶段 7 [多级别联立](https://chanlunzhan.com/glossary/duojibielianli)的预演。

## 这一课的要点

- 二买 = 一买之后向上走一段，再回抽且不创新低的那个低点

- 一买是推论（由背驰得出），二买是事实验证（回抽实际没破）

- 严格定义下二买依赖一买；[宽松口径](https://chanlunzhan.com/glossary/kuansongbi)允许无一买的二买，本站采用[严格口径](https://chanlunzhan.com/glossary/yangebi)

- 二买的级别继承自一买

- 判断二买要同时看本级别的位置关系和次级别的回抽结构
