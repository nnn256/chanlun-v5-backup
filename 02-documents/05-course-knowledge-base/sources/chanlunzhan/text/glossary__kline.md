# K线

又称 K 线、蜡烛图

用开盘、收盘、最高、最低四个价格记录一个时间周期内价格走过的范围。

一根 K 线压缩了一个[周期](https://chanlunzhan.com/glossary/zhouqi)内的四个价格：开盘价、收盘价、最高价、最低价。实体部分是开盘价和收盘价之间的区间，上下影线分别延伸到最高价和最低价。

在缠论里，K 线的颜色和实体大小几乎不重要，重要的只有高点和低点两个数。[包含处理](https://chanlunzhan.com/glossary/baohan)、[分型](https://chanlunzhan.com/glossary/fenxing)、[笔](https://chanlunzhan.com/glossary/bi)的所有判定都只用到高低点。这是缠论和大多数「看阴阳线形态」的技术分析最直接的分歧：形态学关心这根线长什么样，缠论只关心它占据了哪个价格区间。
