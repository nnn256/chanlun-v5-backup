# 回拉零轴

又称 黄白线回拉

中枢震荡期间 MACD 的 DIF 线回到零轴附近，是趋势背驰成立的辅助条件之一。

第 24 课要求在判断[趋势背驰](https://chanlunzhan.com/glossary/qushibeichi)时，[中枢区间](https://chanlunzhan.com/glossary/zg-zd)内 [MACD](https://chanlunzhan.com/glossary/macd) 的黄白线（DIF / DEA）要有回拉零轴的过程。它的含义是前一段的动能已经被震荡消化掉，后续的[离开段](https://chanlunzhan.com/glossary/lijinzoushi)是重新蓄力的结果，两段才具备可比性。

原文没有给出「回到零轴附近」的精确[量](https://chanlunzhan.com/glossary/chengjiaoliang)化标准。本站的实现用「DIF 回到[进入段](https://chanlunzhan.com/glossary/jinruduan)极值的 25% 以内（含穿越零轴）」作为工程判据——这是一个近似，换一个阈值结果可能不同，使用时要意识到这一点。

系统学习

这个概念属于 [阶段 5·动力学与背驰](https://chanlunzhan.com/learn/beichi)。MACD 只是辅助工具而非缠论本体。背驰的判断，以及盘整背驰与趋势背驰的区别。
