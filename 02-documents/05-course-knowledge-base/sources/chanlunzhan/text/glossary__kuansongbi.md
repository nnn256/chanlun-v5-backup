# 宽松笔

又称 老笔、宽松口径

只要求顶底分型不共用 K 线的划笔口径，对应第 79 / 80 / 106 课。

宽松[笔](https://chanlunzhan.com/glossary/bi)把间隔要求放宽到「两个[分型](https://chanlunzhan.com/glossary/fenxing)不共用 [K 线](https://chanlunzhan.com/glossary/kline)」，索引差 3 即可成笔。它划出的笔更多更细，对转折反应更快，但也更容易被噪音干扰。

原文里两种口径并存且从未明确裁决哪个才对，这是缠论学习中一个真实存在的分歧点。本站的态度是把开关摆在明面上，让学员自己看结构随口径怎么变，而不是假装只有一种正确答案。

系统学习

这个概念属于 [阶段 2·基本构件](https://chanlunzhan.com/learn/fenxing-bi)。第一次动手。包含处理 → 分型 → 笔，三个知识点递进，每个都配可交互的分步演示。
