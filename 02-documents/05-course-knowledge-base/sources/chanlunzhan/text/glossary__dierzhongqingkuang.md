# 第二种情况

又称 线段划分第二种情况

分界点前后的特征元素之间存在缺口，需要反向走势自身的特征序列出现分型才确认。

e1 和 e2 之间有缺口时属于第二种情况。此时不能仅凭一个[分型](https://chanlunzhan.com/glossary/fenxing)就确认[线段](https://chanlunzhan.com/glossary/xianduan)结束，必须由从极值点开始的反向走势自己的[特征序列](https://chanlunzhan.com/glossary/tezhengxulie)（与原线段同向的那些[笔](https://chanlunzhan.com/glossary/bi)）做包含合并后出现分型，才算确认。

更关键的是：确认之前如果价格创出了新的极值，假设就被取消，前后合并为同一段。第 78 课的 A+B+C 讨论和第 81 课的图例讲的都是这件事。

系统学习

这个概念属于 [阶段 3·线段](https://chanlunzhan.com/learn/xianduan)。绝大多数自学者卡住的地方，所以单独成阶、节奏最慢。特征序列、两种情况、破坏与确认、取消与回收。
