# 分类而非预测

又称 不测而测

缠论不预测价格，只对当下走势做完全分类，并确定各类的边界。

原文里那段「真正的预测，就是不测而测……问题不是去预测什么，而是确定分段边界」，是缠论区别于其他技术分析的根子。

大多数技术分析在回答「接下来会涨还是会跌」。缠论换了个问题：当下这段走势属于哪一类，它的边界在哪里。分类是穷尽的——[上涨](https://chanlunzhan.com/glossary/qushi)、下跌、[盘整](https://chanlunzhan.com/glossary/panzheng)三选一，没有第四种可能，所以分类结论一定为真，只是分类会随走势演化而改变。

理解这一点之后再看[三类买卖点](https://chanlunzhan.com/glossary/sanleimaimaidian)，就会明白它们首先是位置的分类标签，而不是操作指令。
