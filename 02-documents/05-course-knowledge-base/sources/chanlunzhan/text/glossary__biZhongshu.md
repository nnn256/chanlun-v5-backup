# 笔中枢

又称 笔的中枢

用笔而不是线段作为次级别单元构造出的中枢，是民间扩展而非原文口径。

原文（第 63 课）明确最低[级别](https://chanlunzhan.com/glossary/jibie)[中枢](https://chanlunzhan.com/glossary/zhongshu)的[次级别](https://chanlunzhan.com/glossary/cijibie)单元是[线段](https://chanlunzhan.com/glossary/xianduan)。但实践中[笔](https://chanlunzhan.com/glossary/bi)中枢被广泛使用，因为它出现得更频繁，在较短的样本里也能看到结构。

本站两种都算并分层显示，理由很实际：800 根日线里段中枢往往只有一两个，教学时不够用。但页面会明确标注笔中枢是扩展口径，避免学员误以为它是原文定义。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
