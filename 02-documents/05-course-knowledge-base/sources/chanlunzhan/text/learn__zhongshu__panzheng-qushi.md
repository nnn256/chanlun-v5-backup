# 盘整与趋势

给定一段走势，判断它属于盘整还是趋势，并说出依据。

这一课把前面所有东西串起来。

## 两种走势类型，就两种

[盘整](https://chanlunzhan.com/glossary/panzheng)：只有一个[中枢](https://chanlunzhan.com/glossary/zhongshu)的[走势类型](https://chanlunzhan.com/glossary/zoushileixing)。

趋势：两个或以上依次同向的中枢构成的走势类型。
向上排列是上涨[趋势](https://chanlunzhan.com/glossary/qushi)，向下排列是下跌趋势。

没有第三种。这就是缠论的[走势分解定理](https://chanlunzhan.com/glossary/fenjieddingli)：
任何走势都可以分解为盘整和趋势的有限序列。

回到「走势终完美」

现在可以给阶段 1 的那句话一个精确的说法了：

任何一段进行中的走势，最终会归入盘整或趋势之一。
「[未完成](https://chanlunzhan.com/glossary/weiwancheng)」的意思就是「还不能确定归入哪一类」——
比如只有一个中枢、后面还没走出去，此时可能延伸成更大的盘整，
也可能走出第二个中枢变成趋势。

它一定会变成其中一个。这就是「终完美」。

## 「依次同向」是什么意思

趋势要求中枢依次同向，这四个字有具体含义：

- 依次：中枢之间按时间先后排列，中间由一段走势连接

- 同向：后一个中枢整体高于前一个（上涨），或整体低于前一个（下跌）

「整体高于」的严格说法是：后一个中枢的 ZD 高于前一个中枢的 [ZG](https://chanlunzhan.com/glossary/zg-zd)——
两个中枢的区间不重叠，且后者在上。

如果两个中枢的区间有重叠，它们不构成趋势，
而是可能在更高[级别](https://chanlunzhan.com/glossary/jibie)上合并成一个中枢（上一课讲的扩展）。

## 判断流程

给一段走势，判断类型的流程是机械的：

- [划笔](https://chanlunzhan.com/glossary/bi) → 划[线段](https://chanlunzhan.com/glossary/xianduan)

- 找出所有中枢

- 数中枢的个数

- 一个 → 盘整；多个 → 检查是否依次同向

- 依次同向 → 趋势；有重叠 → 考虑合并成更大级别的中枢，回到第 3 步

注意第 5 步的循环：合并之后中枢数[量](https://chanlunzhan.com/glossary/chengjiaoliang)减少，可能从「两个中枢」
变成「一个更大的中枢」，走势类型也就从趋势变成了盘整。

这就是[走势多义性](https://chanlunzhan.com/glossary/zoushiduoyixing)的来源之一。 在什么级别上看，决定了你数出几个中枢。

## 为什么这个分类有用

三个理由。

第一，它是完全的。 每一段都有归属，不存在「说不清」的情况。
这是任何分类体系的基本要求，但技术分析里做到的不多。

第二，它是可检验的。 中枢的判定是纯计算，
两个人对同一段走势（在同一级别、同一口径下）会数出同样多的中枢。

第三，它是后续所有判断的基础。 阶段 5 的[背驰](https://chanlunzhan.com/glossary/beichi)要先知道是不是趋势
（[趋势背驰](https://chanlunzhan.com/glossary/qushibeichi)和[盘整背驰](https://chanlunzhan.com/glossary/panzhengbeichi)的判定标准不同），阶段 6 的[买卖点](https://chanlunzhan.com/glossary/sanleimaimaidian)定义直接引用了
趋势和中枢的概念。

分类不是操作指令

知道「这是一段上涨趋势」不意味着应该买入。趋势是对已经发生的走势的描述，
而不是对未来的预测。

一段趋势在被确认为趋势的时候，它已经走完了——因为确认需要
第二个中枢完成，而中枢完成时那段行情已经过去了。

这不是缠论的缺陷，是分类方法的本质：分类只能针对已完成的事。
把分类当信号用，是从「学缠论」滑向「用缠论炒股」的第一步，
而本站到分类为止。

多级别联立（阶段 7）。

## 这一课的要点

- 盘整 = 一个中枢；趋势 = 两个及以上依次同向的中枢

- 「依次同向」要求后一中枢的 ZD 高于前一中枢的 ZG（上涨），反之亦然

- 中枢区间重叠时不构成趋势，考虑在更高级别合并

- 走势分解定理：任何走势都能分解为盘整与趋势的有限序列

- 分类只针对已完成的走势，趋势被确认时行情已经走过了
