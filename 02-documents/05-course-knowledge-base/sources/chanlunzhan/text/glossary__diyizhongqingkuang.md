# 第一种情况

又称 线段划分第一种情况

线段分界点前后的特征元素之间没有缺口，此时特征序列出现分型即确认线段结束。

把假设的分界点前最后一个[特征元素](https://chanlunzhan.com/glossary/tezhengxulie)记为 e1，分界点之后的第一个反向[笔](https://chanlunzhan.com/glossary/bi)记为 e2。如果 e1 和 e2 的区间有重叠（没有缺口），就属于第一种情况。

这时只需要分界点之后的特征元素做包含合并后出现[分型](https://chanlunzhan.com/glossary/fenxing)，[线段](https://chanlunzhan.com/glossary/xianduan)即在该极值处结束。判定相对直接。

系统学习

这个概念属于 [阶段 3·线段](https://chanlunzhan.com/learn/xianduan)。绝大多数自学者卡住的地方，所以单独成阶、节奏最慢。特征序列、两种情况、破坏与确认、取消与回收。
