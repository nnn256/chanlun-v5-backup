# 关于本站

缠论的资料在网上不算少，但对初学者来说有两个共同的问题： 要么是原文的直接转载，没有图、没有导读，按博客发表顺序排列，读到第二十课还没见过分型的定义； 要么是各种指标插件和选股工具，直接给你画好的线，但不告诉你为什么这么画。

这个站想解决的就是中间那段：把原文里的严格定义，用真实的 A 股图讲清楚， 并且让你自己动手画一遍。

## 站里有什么

- [七阶课程](https://chanlunzhan.com/learn)，共 26 节。从「K 线的四个价格是什么」一直到多级别联立分析， 每一阶都有通关标准，前一阶没过不建议往下走。

- [113 篇原文](https://chanlunzhan.com/108)，各自成页，按七阶体系重新编组，每篇配导读、术语链接和原始出处。

- [52 条概念词典](https://chanlunzhan.com/glossary)，每条给出严格定义和常见误解。

- [图上训练](https://chanlunzhan.com/practice)，用真实历史走势出题，从判断分型到完整拆图，共四种模式。

## 几点说明

结构是当场算出来的，不是提前画好的图片。你在参数实验室里换一种笔的口径，或者在个股页展开某一层结构， 图上的线会立刻重画。这样你才能看到「改一个前提，结论跟着变」这件事。

站内的行情不是实时的。所有 K 线都是某个时间点的快照，之后不会自动更新， 每个用到数据的页面都标了截止日期。这是学习素材，不是行情工具。

不需要注册。学习进度和错题本保存在你当前这台设备的浏览器里，换设备或清空浏览器数据就会丢失。

## 算法口径

结构识别基于开源项目[chanlun-kline](https://github.com/mikonos/chanlun-kline)（MIT）。选它的原因是它的每条规则都能对应到原文的具体课号， 出处可查；第 81 课的原文图例被用作校验的基准。

需要坦白的是，缠论没有唯一的标准实现。 线段的划分和背驰的力度比较，原文都留有解释空间，不同流派的结论会不一样。 本站在[参数实验室](https://chanlunzhan.com/practice/lab)里主动展示这些差异，而不是假装算法输出就是标准答案。
