# 线段破坏

又称 线段的破坏

特征序列出现分型，意味着原线段的延续被打断。

[线段](https://chanlunzhan.com/glossary/xianduan)的破坏是指[特征序列](https://chanlunzhan.com/glossary/tezhengxulie)出现了反向[分型](https://chanlunzhan.com/glossary/fenxing)，提示原线段可能已经结束。但破坏不等于确认——[第二种情况](https://chanlunzhan.com/glossary/dierzhongqingkuang)下还需要额外的确认步骤。

把「破坏」和「确认结束」分开理解很重要：破坏是必要条件，确认才是充分条件。

系统学习

这个概念属于 [阶段 3·线段](https://chanlunzhan.com/learn/xianduan)。绝大多数自学者卡住的地方，所以单独成阶、节奏最慢。特征序列、两种情况、破坏与确认、取消与回收。
