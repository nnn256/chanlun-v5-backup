# 盘整

又称 缠中说禅盘整

只包含一个中枢的完成的走势类型。

第 17 课的定义：在任何[级别](https://chanlunzhan.com/glossary/jibie)的任何走势中，某完成的[走势类型](https://chanlunzhan.com/glossary/zoushileixing)只包含一个[走势中枢](https://chanlunzhan.com/glossary/zhongshu)，就称为该级别的盘整。

注意这个定义与涨跌幅度无关。一段涨了 50% 的走势，只要它只有一个中枢，就是盘整。反过来，一段几乎横着走的行情，如果形成了两个依次下移的中枢，那就是下跌[趋势](https://chanlunzhan.com/glossary/qushi)。用「涨得多不多」去判断趋势还是盘整，是最常见的错误。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
