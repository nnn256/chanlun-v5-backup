# 区间套

用逐级降低级别的方式不断收窄背驰点的位置区间，直到精度满足需要。

在本[级别](https://chanlunzhan.com/glossary/jibie)判断出[背驰](https://chanlunzhan.com/glossary/beichi)之后，到[次级别](https://chanlunzhan.com/glossary/cijibie)去看这段离开走势的内部结构，找出次级别的背驰点；再到次次级别去找，如此逐层深入。每深入一层，可能的位置区间就收窄一次。

区间套是缠论里精度最高的定位方法，也是最考验多级别功力的部分。本站的算法实现目前未包含区间套，这一层需要手工在多个级别之间对照完成。
