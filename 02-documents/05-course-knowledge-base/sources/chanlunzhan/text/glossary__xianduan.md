# 线段

又称 缠论线段

至少由三笔构成、且被特征序列分型确认结束的走势单元，是构成中枢的基本材料。

线段由至少三[笔](https://chanlunzhan.com/glossary/bi)构成，起止笔与线段同向，所以完成的线段笔数必定是单数。判定线段是否结束，靠的是[特征序列](https://chanlunzhan.com/glossary/tezhengxulie)出现[分型](https://chanlunzhan.com/glossary/fenxing)。

第 71 课给出的程序是「假设—检验」：先假设某个转折点是分界点，然后用线段划分的两种情况去考察是否满足，满足其一就是真分界，都不满足则原线段延续。

线段是绝大多数自学者卡住的地方，原因是特征序列的[包含处理](https://chanlunzhan.com/glossary/baohan)规则和分界点两侧是否合并这些细节在原文里分散在好几课里，而且存在解释空间。
