# 包含关系

又称 包含处理、K线包含

相邻两根 K 线中一根的高低点区间完全落在另一根内，需要合并成一根再做后续判断。

如果相邻两根 [K 线](https://chanlunzhan.com/glossary/kline)满足「一根的高点不低于另一根的高点，且低点不高于另一根的低点」，两者就存在包含关系。缠论要求先把它们合并成一根，才能往下判[分型](https://chanlunzhan.com/glossary/fenxing)。

合并的方向由之前的走势方向决定，不是由这两根自己决定：向上时高点取两者较高、低点也取较高；向下时高点取较低、低点也取较低。注意不是简单取「最大区间」——那样做只会让包含关系永远消不掉。

合并还要遵守顺序原则（第 65 课）：先把第 1、2 根合并成新 K 线，再拿这根新 K 线去和第 3 根比，而不是三根一起处理。

包含处理的意义在于：处理之后相邻 K 线的高低点严格同向变化，分型的定义才能成立。

系统学习

这个概念属于 [阶段 2·基本构件](https://chanlunzhan.com/learn/fenxing-bi)。第一次动手。包含处理 → 分型 → 笔，三个知识点递进，每个都配可交互的分步演示。
