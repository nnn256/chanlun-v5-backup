# 离开段

又称 离开中枢

从中枢区间脱离并且不再回来的那一段走势。

[中枢](https://chanlunzhan.com/glossary/zhongshu)结束时，最后有一段走势脱离[中枢区间](https://chanlunzhan.com/glossary/zg-zd)且一去不回，这就是离开段。判定上要看它之后的那一段是否拉回中枢：拉回了说明只是震荡的一部分，没拉回才是真正的离开。

离开段不计入中枢，它的高低点也不参与 [GG](https://chanlunzhan.com/glossary/gg-dd) / DD 的计算。[背驰](https://chanlunzhan.com/glossary/beichi)判断比较的正是离开段与[进入段](https://chanlunzhan.com/glossary/jinruduan)的[力度](https://chanlunzhan.com/glossary/lidu)。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
