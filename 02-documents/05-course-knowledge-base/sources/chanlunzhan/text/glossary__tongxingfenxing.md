# 同性分型

又称 同性分型取舍

连续出现的多个同类型分型，按「顶取不低者、底取不高者」只保留一个。

[划笔](https://chanlunzhan.com/glossary/bi)时经常遇到连续几个[顶分型](https://chanlunzhan.com/glossary/fenxing)中间没有合格的底分型。第 77 课给出的处理是三步骤取舍：连续的顶分型保留价格不低的那个，连续的底分型保留不高的那个，价格相等时取先出现的。

这条规则保证了笔的端点序列必然顶底交替，也保证了每一笔都落在局部的极值上。
