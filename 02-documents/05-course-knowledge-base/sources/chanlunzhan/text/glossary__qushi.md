# 趋势

又称 缠中说禅趋势、上涨、下跌

至少包含两个以上依次同向的中枢的完成的走势类型。方向向上叫上涨，向下叫下跌。

第 17 课的定义：某完成的[走势类型](https://chanlunzhan.com/glossary/zoushileixing)至少包含两个以上依次同向的[走势中枢](https://chanlunzhan.com/glossary/zhongshu)，就称为趋势。依次同向的判定用 [GG](https://chanlunzhan.com/glossary/gg-dd) / DD——后一个中枢的 DD 高于前一个的 GG 即为上涨。

趋势的重要性在于它是[背驰](https://chanlunzhan.com/glossary/beichi)的前提。第 27 课说得很清楚：没有趋势就没有背驰。只有一个中枢的[盘整](https://chanlunzhan.com/glossary/panzheng)里谈的是[盘整背驰](https://chanlunzhan.com/glossary/panzhengbeichi)，那是另一回事。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
