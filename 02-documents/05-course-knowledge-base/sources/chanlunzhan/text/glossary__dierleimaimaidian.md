# 第二类买卖点

又称 二买、二卖、第二类买点、第二类卖点

第一类买卖点之后，次级别回抽不创新极值的那个位置。

[第一类买点](https://chanlunzhan.com/glossary/diyileimaimaidian)出现后，走势通常会有一次反弹再回抽。如果这次回抽没有跌破一买的低点，回抽的低点就是第二类买点。第二类卖点对称。

第 21 课和第 53 课讨论的重点是「第二段[次级别](https://chanlunzhan.com/glossary/cijibie)走势的极值点」这个表述的精确含义。二买的结构意义在于它验证了一买处的[力度](https://chanlunzhan.com/glossary/lidu)衰竭是真实的。

系统学习

这个概念属于 [阶段 6·三类买卖点](https://chanlunzhan.com/learn/maimaidian)。只讲结构定义，不讲怎么交易。一二三类买卖点在缠论里首先是走势分类的产物，不是操作信号。
