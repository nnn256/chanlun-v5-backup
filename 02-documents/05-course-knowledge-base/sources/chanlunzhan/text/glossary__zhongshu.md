# 走势中枢

又称 中枢、缠中说禅走势中枢

某级别走势类型中，被至少三个连续次级别走势类型所重叠的价格区间。

中枢是缠论真正的核心概念。定义（第 17 课）是：某[级别](https://chanlunzhan.com/glossary/jibie)[走势类型](https://chanlunzhan.com/glossary/zoushileixing)中，被至少三个连续[次级别](https://chanlunzhan.com/glossary/cijibie)走势类型所重叠的部分。

构造上，取进入之后的连续三段，它们高点的最小值就是 ZG（中枢上沿），低点的最大值是 ZD（中枢下沿）。只有 [ZG](https://chanlunzhan.com/glossary/zg-zd) > ZD 时中枢才成立。[中枢震荡](https://chanlunzhan.com/glossary/zhongshuyanshen)期间的最高点记作 [GG](https://chanlunzhan.com/glossary/gg-dd)，最低点记作 DD。

一个常见误解是把[进入中枢](https://chanlunzhan.com/glossary/jinruduan)的那一段也算进中枢。中枢是由进入之后的三段重叠形成的，进入段不计入。

中枢的意义在于它把连续的价格运动切成了可分类的块：一个中枢是[盘整](https://chanlunzhan.com/glossary/panzheng)，两个以上依次同向的中枢是[趋势](https://chanlunzhan.com/glossary/qushi)。缠论的走势分类完全建立在中枢之上。
