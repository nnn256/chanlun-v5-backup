# 走势类型

又称 走势分类

任何级别的走势都能且只能分解成上涨、下跌、盘整三类。

这是缠论全部理论的出发点：任何[级别](https://chanlunzhan.com/glossary/jibie)的所有走势，都能分解成[趋势](https://chanlunzhan.com/glossary/qushi)与[盘整](https://chanlunzhan.com/glossary/panzheng)两类，趋势又分上涨与下跌。这个结论不是推导出来的，是从大[量](https://chanlunzhan.com/glossary/chengjiaoliang)图形中总结出来的经验，但它是整套理论唯一坚实的基础。

走势类型由[中枢](https://chanlunzhan.com/glossary/zhongshu)数量决定：一个中枢是盘整，两个以上依次同向的中枢是趋势。相邻的走势类型共享[连接点](https://chanlunzhan.com/glossary/lianjiedian)。
