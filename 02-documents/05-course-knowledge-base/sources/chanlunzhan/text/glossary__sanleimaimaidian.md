# 三类买卖点

又称 买卖点、缠论买卖点

缠论对走势位置的三种结构分类，是分类的产物而不是操作信号。

一二三类买卖点在缠论里首先是[走势分类](https://chanlunzhan.com/glossary/zoushileixing)的结果：它们标记的是「这段走势走到了什么位置」，而不是「现在该买还是该卖」。

第一类对应[趋势背驰](https://chanlunzhan.com/glossary/qushibeichi)点，第二类对应第一类之后的[次级别](https://chanlunzhan.com/glossary/cijibie)回抽不创新极值，第三类对应[离开中枢](https://chanlunzhan.com/glossary/lijinzoushi)后回试不破中枢边界。三者的判据各自独立，都建立在中枢和走势类型之上。

本站只讲这些结构如何定义、如何在图上识别，不讲任何交易方法，也不提供买卖建议。
