# 中枢新生

原中枢结束后，走势在新的价格区间形成另一个中枢。

价格连续两段脱离原[中枢区间](https://chanlunzhan.com/glossary/zg-zd)后，原中枢结束。如果之后又有连续三段形成新的重叠区间，就是一个新生的中枢。

相邻[中枢](https://chanlunzhan.com/glossary/zhongshu)的位置关系决定了[走势类型](https://chanlunzhan.com/glossary/zoushileixing)：依次上移是上涨[趋势](https://chanlunzhan.com/glossary/qushi)，依次下移是下跌趋势，位置重叠则是扩展关系。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
