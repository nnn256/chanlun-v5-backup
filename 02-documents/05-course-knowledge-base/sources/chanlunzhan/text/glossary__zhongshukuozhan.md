# 中枢扩展

两个相邻中枢的波动区间发生重叠，实质上构成一个更高级别的中枢。

当后一个[中枢](https://chanlunzhan.com/glossary/zhongshu)的 [GG](https://chanlunzhan.com/glossary/gg-dd) / DD 区间和前一个重叠时，两者不构成[趋势](https://chanlunzhan.com/glossary/qushi)关系。第 33 课把这种情况归为扩展：这两个中枢在更高[级别](https://chanlunzhan.com/glossary/jibie)上其实是同一个中枢的一部分。

本站的实现在这种情况下不做合并，而是让它们各自成为[盘整](https://chanlunzhan.com/glossary/panzheng)[走势类型](https://chanlunzhan.com/glossary/zoushileixing)，把重叠留给上一级[递归](https://chanlunzhan.com/glossary/diguijibie)去处理。这是[走势多义性](https://chanlunzhan.com/glossary/zoushiduoyixing)下的一个确定性选择，不是唯一解。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
