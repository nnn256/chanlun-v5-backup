# 进入段

又称 进入中枢

把走势带进中枢区间的那一段，位于中枢之前，不计入中枢本身。

[中枢](https://chanlunzhan.com/glossary/zhongshu)由进入之后的连续三段重叠形成，所以进入段本身不在中枢里。这是初学者最容易数错的地方：看到四段重叠就以为中枢有四段，实际上第一段是进入段。

进入段在[背驰](https://chanlunzhan.com/glossary/beichi)判断中扮演基准角色——[离开段](https://chanlunzhan.com/glossary/lijinzoushi)的[力度](https://chanlunzhan.com/glossary/lidu)要和它比。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
