# 走势中枢的定义

在图上正确框出中枢，并说出它的四个特征值。

到这里，你已经能把 [K 线](https://chanlunzhan.com/glossary/kline)变成[笔](https://chanlunzhan.com/glossary/bi)、把笔变成[线段](https://chanlunzhan.com/glossary/xianduan)。这一课把线段变成[中枢](https://chanlunzhan.com/glossary/zhongshu)——
缠论真正的核心。

## 定义

连续三段同[级别](https://chanlunzhan.com/glossary/jibie)走势，如果它们有重叠的价格区间，这个重叠区间就是一个走势中枢。

「三段」在不同级别上指不同的东西：

- 用线段构造 → 段中枢（本站图上的「段中枢」层）

- 用笔构造 → [笔中枢](https://chanlunzhan.com/glossary/biZhongshu)，级别更低

三段的方向必然是「上下上」或「下上下」（因为方向交替）。
第一段和第三段同向，中间那段反向。

## 四个值

中枢确定后有四个特征值，务必分清：

| 值 | 含义 | 怎么算 |
| --- | --- | --- |
| ZG | 中枢区间上沿 | 构成中枢的三段各自高点中的最小值 |
| ZD | 中枢区间下沿 | 三段各自低点中的最大值 |
| GG | 中枢期间最高点 | 三段高点中的最大值 |
| DD | 中枢期间最低点 | 三段低点中的最小值 |

ZG/ZD 是重叠区间，GG/DD 是波动范围

这是最容易混的地方，用一句话记住：

ZG 到 ZD 是「三段都到过」的区间；GG 到 DD 是「至少一段到过」的区间。

ZG–ZD 必然被包含在 GG–DD 之内。画中枢的框，画的是 ZG–ZD，
不是 GG–DD。用 GG–DD 画框是初学者最典型的错误。

中枢成立的条件就是 ZG > ZD——重叠区间非空。
如果三段的高点最小值低于低点最大值，说明它们没有共同的重叠区，不构成中枢。

## 一个计算例子

三段线段：

| 段 | 低点 | 高点 |
| --- | --- | --- |
| 第一段（上） | 10.0 | 13.0 |
| 第二段（下） | 11.0 | 13.0 |
| 第三段（上） | 11.0 | 14.0 |

- ZG = min(13.0, 13.0, 14.0) = 13.0

- ZD = max(10.0, 11.0, 11.0) = 11.0

- GG = max(13.0, 13.0, 14.0) = 14.0

- DD = min(10.0, 11.0, 11.0) = 10.0

ZG (13.0) > ZD (11.0)，中枢成立，区间是 11.0–13.0。
中枢期间价格在 10.0–14.0 之间波动过，但只有 11.0–13.0 是三段共同覆盖的。

## 进入段与离开段

中枢不是孤立的。它前面有一段走势把价格带进来，后面有一段把价格带出去：

- [进入段](https://chanlunzhan.com/glossary/jinruduan)：走进中枢之前的那一段

- [离开段](https://chanlunzhan.com/glossary/lijinzoushi)：走出中枢之后的那一段

这两个概念在后面判断[趋势](https://chanlunzhan.com/glossary/qushi)和[背驰](https://chanlunzhan.com/glossary/beichi)时会反复用到。特别是离开段——
一段趋势里，前一个中枢的离开段往往就是后一个中枢的进入段，
它们把中枢串起来。

## 中枢不是支撑压力区

必须强调这一点，因为这是从传统技术分析过来的人最容易犯的错。

支撑压力区的思路是：「价格到这里会反弹/回落」，它是一个关于未来的预测。

中枢不是。中枢是一个已经完成的结构事实——三段走势在这里重叠过，
仅此而已。它不预言价格到这里会怎样。

那中枢有什么用？它的用处是分类：数一数一段走势里有几个中枢、
它们怎么排列，就能确定这段走势是[盘整](https://chanlunzhan.com/glossary/panzheng)还是趋势。这是下下课的内容。

不要用中枢做支撑压力

把 ZG 当压力位、ZD 当支撑位来用，是对中枢最常见的误用。

这么用不是完全没有依据（重叠区确实有一定的价格意义），
但它偏离了缠论的框架。缠论里中枢的角色是[走势分类](https://chanlunzhan.com/glossary/zoushileixing)的依据，
不是价位预测。

## 三段还是九段

原文里有一个细节：严格来说，一个中枢由「三个连续[次级别](https://chanlunzhan.com/glossary/cijibie)走势类型」的重叠构成。
而在实操里我们用的是「三段」——三笔或三线段。

这两者在多数情况下等价，因为一段本身就是次级别走势类型。
但在级别边界处会有差异，这属于第七阶的内容。

现在按「三段重叠」来理解和操作就可以。

## 这一课的要点

- 中枢 = 连续三段同级别走势的重叠区间，方向必然是上下上或下上下

- ZG = 三段高点的最小值，ZD = 三段低点的最大值，重叠区间

- GG = 三段高点的最大值，DD = 三段低点的最小值，波动范围

- 中枢成立条件：ZG > ZD；画框画 ZG–ZD，不是 GG–DD

- 中枢是已完成的结构事实，用于走势分类，不是支撑压力预测
