# 笔

又称 缠论笔、划笔

由一个顶分型和一个底分型连接而成的最小走势单元，两端之间必须有足够的独立 K 线。

笔连接相邻的一顶一底。成立条件（[严格口径](https://chanlunzhan.com/glossary/yangebi)，第 77 课）有三条：一顶一底；[顶分型](https://chanlunzhan.com/glossary/fenxing)和底分型之间至少有一根不属于这两个分型的 [K 线](https://chanlunzhan.com/glossary/kline)；顶分型最高 K 线的区间至少有一部分高于底分型最低 K 线的区间。

实现上，「至少隔一根独立 K 线」等价于两个分型在[包含处理](https://chanlunzhan.com/glossary/baohan)后的数组里索引差至少为 4——两个分型各占 3 根，中间还要留 1 根。

笔的方向只由两端分型的类型决定：底到顶是向上笔，顶到底是向下笔，中间怎么走不影响方向。相邻两笔的方向必然交替。

系统学习

这个概念属于 [阶段 2·基本构件](https://chanlunzhan.com/learn/fenxing-bi)。第一次动手。包含处理 → 分型 → 笔，三个知识点递进，每个都配可交互的分步演示。
