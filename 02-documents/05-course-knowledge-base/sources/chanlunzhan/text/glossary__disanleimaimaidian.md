# 第三类买卖点

又称 三买、三卖、第三类买点、第三类卖点

次级别走势向上离开中枢后，第一次回试不跌破 ZG 的位置。

第 20 课的定义：某[级别](https://chanlunzhan.com/glossary/jibie)[走势类型](https://chanlunzhan.com/glossary/zoushileixing)的[中枢](https://chanlunzhan.com/glossary/zhongshu)结束后，价格以[次级别](https://chanlunzhan.com/glossary/cijibie)走势离开该中枢，第一次回试不跌破 [ZG](https://chanlunzhan.com/glossary/zg-zd)（中枢上沿）的那个位置就是第三类买点；向下离开后第一次回抽不升破 ZD 的位置是第三类卖点。

「第一次」这个限定很关键——只看紧邻的回试段，不是任何一次不破 ZG 都算。三买的结构含义是原中枢已经被有效离开，走势进入了新的层级。

[三类买卖点](https://chanlunzhan.com/glossary/sanleimaimaidian)是三者中判据最清晰、最容易在图上识别的，因为它只依赖中枢边界，不依赖 [MACD](https://chanlunzhan.com/glossary/macd)。

系统学习

这个概念属于 [阶段 6·三类买卖点](https://chanlunzhan.com/learn/maimaidian)。只讲结构定义，不讲怎么交易。一二三类买卖点在缠论里首先是走势分类的产物，不是操作信号。
