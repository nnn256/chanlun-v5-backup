# 走势分解

又称 完全分类

把一段完整走势自上而下拆成走势类型、中枢、线段、笔的层层结构。

走势分解是缠论的最终能力：拿到一张陌生的图，能从最高[级别](https://chanlunzhan.com/glossary/jibie)开始，说出当下处于什么[走势类型](https://chanlunzhan.com/glossary/zoushileixing)、包含几个[中枢](https://chanlunzhan.com/glossary/zhongshu)、每个中枢由哪些[线段](https://chanlunzhan.com/glossary/xianduan)构成、每条线段由哪些[笔](https://chanlunzhan.com/glossary/bi)构成。

分解的检验标准是无缝且穷尽：相邻走势类型首尾相接不留空隙，所有 [K 线](https://chanlunzhan.com/glossary/kline)都被覆盖，且最后一个走势类型标记为[未完成](https://chanlunzhan.com/glossary/weiwancheng)。
