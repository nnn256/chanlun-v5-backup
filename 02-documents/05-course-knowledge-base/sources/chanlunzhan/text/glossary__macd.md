# MACD

又称 异同移动平均线

由两条指数移动平均线之差构成的辅助指标，缠论用它作为背驰判断的参考。

MACD 由 DIF（快慢均线之差）、DEA（DIF 的均线）和柱体（国内惯例取 2×(DIF−DEA)）组成，标准参数 12 / 26 / 9。

必须明确：MACD 不是缠论的本体。缠论的结论全部由走势结构给出，MACD 只是在判断[背驰](https://chanlunzhan.com/glossary/beichi)时提供一个[力度](https://chanlunzhan.com/glossary/lidu)的[量](https://chanlunzhan.com/glossary/chengjiaoliang)化参考。第 24 课引入它是为了让「力度衰竭」这个直观感受有个可比较的数值，而不是让它变成信号来源。

把 MACD 金叉死叉当成[缠论买卖点](https://chanlunzhan.com/glossary/sanleimaimaidian)，是对这套理论最常见的误用。
