# 口径分歧

又称 流派分歧

缠论原文对笔和线段的部分规则存在并存表述，不同实现选择了不同的处理方式。

缠论原文是连载博客而非教科书，前后期的表述有演进，某些地方并存两种说法且没有最终裁决。最典型的是[笔](https://chanlunzhan.com/glossary/bi)的严格 / [宽松口径](https://chanlunzhan.com/glossary/kuansongbi)，以及[线段](https://chanlunzhan.com/glossary/xianduan)划分中[特征序列](https://chanlunzhan.com/glossary/tezhengxulie)[包含处理](https://chanlunzhan.com/glossary/baohan)的细节。

结果是不同的软件实现对同一段行情可能画出不同的笔和线段。这不是谁写错了代码，而是原文本身留下的空间。学习时要建立的认知是：算法输出不等于唯一真理。本站在参数实验室里主动展示这种差异。

这个概念属于 [阶段 2·基本构件](https://chanlunzhan.com/learn/fenxing-bi)。第一次动手。包含处理 → 分型 → 笔，三个知识点递进，每个都配可交互的分步演示。
