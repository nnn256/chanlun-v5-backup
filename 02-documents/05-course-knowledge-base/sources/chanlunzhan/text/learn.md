# 缠论七阶课程

一个预备阶段加七个正式阶段，共 26 节， 从「K 线的四个价格是什么」讲到「拿到一张陌生日线图能自上而下完整分解」。 每一阶都有明确的通关标准，学完做一次小测就知道自己过没过。

顺序是有讲究的，不建议跳。缠论的概念是层层依赖的：没有笔就没有线段， 没有线段就没有中枢，没有中枢就谈不上背驰和买卖点。 直接从中枢开始看，是自学者放弃的最常见原因。

这个课程不教交易

包括第六阶的「三类买卖点」在内，全程只讲结构定义。 买卖点在缠论里首先是走势分类的产物，不是操作信号。
