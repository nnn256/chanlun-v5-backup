# 分型

又称 顶分型、底分型

包含处理后连续三根 K 线中，中间那根的高低点同时最高（顶分型）或同时最低（底分型）。

分型是缠论最小的结构单位。取[包含处理](https://chanlunzhan.com/glossary/baohan)后的连续三根 [K 线](https://chanlunzhan.com/glossary/kline)：中间那根的高点高于左右两根、低点也高于左右两根，就是顶分型；中间那根高低点都最低，就是底分型。

两个关键点常被忽略：第一，判定必须用包含处理之后的 K 线，直接看原始 K 线会得出完全不同的结果；第二，高点条件和低点条件在包含处理后是等价的，所以实现上只需比较一侧。

分型本身不构成买卖依据，它只是[划笔](https://chanlunzhan.com/glossary/bi)的原材料。一个分型出现并不意味着[趋势](https://chanlunzhan.com/glossary/qushi)反转，绝大多数分型最终都不会成为笔的端点。

这个概念属于 [阶段 2·基本构件](https://chanlunzhan.com/learn/fenxing-bi)。第一次动手。包含处理 → 分型 → 笔，三个知识点递进，每个都配可交互的分步演示。
