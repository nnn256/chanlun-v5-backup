# 连接点

又称 走势类型连接

相邻两个走势类型共享的那个端点，前一个的终点即后一个的起点。

第 36 课讨论[走势类型](https://chanlunzhan.com/glossary/zoushileixing)如何连接：下一个走势类型的第一个[中枢](https://chanlunzhan.com/glossary/zhongshu)的[进入段](https://chanlunzhan.com/glossary/jinruduan)属于下一个走势类型，它的起点就是前一个走势类型的终点。两个走势类型共享这一个点。

这保证了[走势分解](https://chanlunzhan.com/glossary/zoushifenjie)是无缝的——不会出现某几根 [K 线](https://chanlunzhan.com/glossary/kline)不属于任何走势类型的情况。

系统学习

这个概念属于 [阶段 7·递归与联立](https://chanlunzhan.com/learn/recursion)。把前七阶接起来。级别递归、多级别联立、区间套，以及走势分解的完全分类。
