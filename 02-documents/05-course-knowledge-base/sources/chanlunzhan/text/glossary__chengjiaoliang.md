# 成交量

又称 量

一个周期内成交的股数或手数，缠论中只作为极次要的辅助参考。

成交量在缠论中的地位很低。原文提到过量的配合可以辅助判断[力度](https://chanlunzhan.com/glossary/lidu)，但所有的结构判定——[包含处理](https://chanlunzhan.com/glossary/baohan)、[分型](https://chanlunzhan.com/glossary/fenxing)、[笔](https://chanlunzhan.com/glossary/bi)、[线段](https://chanlunzhan.com/glossary/xianduan)、[中枢](https://chanlunzhan.com/glossary/zhongshu)——完全不使用成交量。

这一点值得初学者特别注意：如果一套「缠论」方法把成交量放在核心位置，那它多半掺进了别的东西。

系统学习

这个概念属于 [阶段 0·看懂一张图](https://chanlunzhan.com/learn/kline-basics)。给完全不懂股票的人。K 线的四个价格、周期的含义、成交量、复权，以及为什么缠论不看指标看结构。
