# 严格笔

又称 新笔、严格口径

要求顶底分型之间至少隔一根独立 K 线的划笔口径，对应第 62 / 69 / 77 课。

严格[笔](https://chanlunzhan.com/glossary/bi)要求两个分型在[包含处理](https://chanlunzhan.com/glossary/baohan)后的序列里索引差至少为 4，也就是[顶分型](https://chanlunzhan.com/glossary/fenxing)的三根和底分型的三根之间还得有至少一根不属于任何一方的 [K 线](https://chanlunzhan.com/glossary/kline)。

严格口径划出的笔更少、更稳，不容易被短期噪音带出一堆碎笔，代价是对快速转折反应慢。本站默认使用严格笔，个股页的参数实验室可以切换到[宽松笔](https://chanlunzhan.com/glossary/kuansongbi)做对照。

系统学习

这个概念属于 [阶段 2·基本构件](https://chanlunzhan.com/learn/fenxing-bi)。第一次动手。包含处理 → 分型 → 笔，三个知识点递进，每个都配可交互的分步演示。
