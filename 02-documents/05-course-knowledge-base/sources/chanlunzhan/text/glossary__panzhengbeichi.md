# 盘整背驰

又称 盘背

在只有一个中枢的盘整走势中出现的力度衰竭。

[盘整](https://chanlunzhan.com/glossary/panzheng)[背驰](https://chanlunzhan.com/glossary/beichi)发生在非[趋势](https://chanlunzhan.com/glossary/qushi)的语境里：只有一个[中枢](https://chanlunzhan.com/glossary/zhongshu)，[进入段](https://chanlunzhan.com/glossary/jinruduan)和[离开段](https://chanlunzhan.com/glossary/lijinzoushi)同向且离开段[力度](https://chanlunzhan.com/glossary/lidu)更小。

它的可靠性通常弱于[趋势背驰](https://chanlunzhan.com/glossary/qushibeichi)，因为盘整中枢随时可能继续延伸。原文对盘整背驰的讨论也远少于趋势背驰。
