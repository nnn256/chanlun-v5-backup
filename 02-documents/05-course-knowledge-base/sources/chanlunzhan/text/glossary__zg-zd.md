# ZG 与 ZD

又称 ZG、ZD、中枢区间

中枢区间的上沿与下沿。ZG 是构成段高点的最小值，ZD 是低点的最大值。

ZG = min(三段各自的高点)，ZD = max(三段各自的低点)。区间 [ZD, ZG] 就是这三段的公共重叠部分，也就是[中枢](https://chanlunzhan.com/glossary/zhongshu)本身。

ZG > ZD 是中枢成立的判据。如果三段没有公共重叠，就不构成中枢，走势按第 17 课的[分解定理](https://chanlunzhan.com/glossary/fenjieddingli)保持原方向继续。

不要把 ZG / ZD 和 [GG](https://chanlunzhan.com/glossary/gg-dd) / DD 混为一谈：前者是重叠区间的边界，后者是震荡过程的极值。[三买](https://chanlunzhan.com/glossary/disanleimaimaidian)三卖的判定用的是 ZG / ZD，中枢间关系的判定用的是 GG / DD。

系统学习

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
