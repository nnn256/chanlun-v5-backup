# 未完成

又称 pending、当下走势

结构序列中最后一个单元的固有状态，源自走势终完美原理。

任何时刻，最后一条[线段](https://chanlunzhan.com/glossary/xianduan)、最后一个[中枢](https://chanlunzhan.com/glossary/zhongshu)、最后一个[走势类型](https://chanlunzhan.com/glossary/zoushileixing)都处于未完成状态——它们还在演化中，随时可能因为后续走势而改变判定。

这不是算法保守，而是理论要求。本站所有的结构输出都会标注这个状态。看到「最新一段未完成」时不要理解成「算法算不出来」，而要理解成「按缠论，它本来就还没完成」。

系统学习

这个概念属于 [阶段 1·缠论的世界观](https://chanlunzhan.com/learn/worldview)。不讲画法，只讲思路。走势终完美、分类而非预测、级别与递归——这三个观念决定了后面所有技术细节的意义。
