# GG 与 DD

又称 GG、DD

中枢震荡期间到达过的最高点与最低点，用于判断相邻中枢之间的关系。

GG 是[中枢](https://chanlunzhan.com/glossary/zhongshu)存续期间所有段的最高点，DD 是最低点。它们描述的是震荡的实际幅度，通常比 [ZG](https://chanlunzhan.com/glossary/zg-zd) / ZD 的区间宽。

第 20 课的中心定理二用 GG / DD 判断相邻中枢的关系：后一个中枢的 DD 高于前一个的 GG 就是[上涨](https://chanlunzhan.com/glossary/qushi)，后一个的 GG 低于前一个的 DD 就是下跌，两者波动区间重叠则是扩展关系，要留给更高[级别](https://chanlunzhan.com/glossary/jibie)去成枢。

这个概念属于 [阶段 4·走势中枢](https://chanlunzhan.com/learn/zhongshu)。缠论真正的核心。中枢的定义与构造、延伸新生扩展，以及由中枢导出的盘整与趋势分类。
