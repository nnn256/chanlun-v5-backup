# 次级别

构成本级别走势的下一层结构单元。

[中枢](https://chanlunzhan.com/glossary/zhongshu)的定义是「至少三个连续次[级别](https://chanlunzhan.com/glossary/jibie)[走势类型](https://chanlunzhan.com/glossary/zoushileixing)的重叠部分」，所以每谈一个中枢都必须先明确它的次级别是什么。

最低级别的中枢，其次级别取[线段](https://chanlunzhan.com/glossary/xianduan)（第 63 课口径）。再往上，次级别就是下一层的走势类型。[递归](https://chanlunzhan.com/glossary/diguijibie)到最底层时不能无限分下去，原文的处理是把最低不可分解级别的中枢定义为「至少三个该级别单位 [K 线](https://chanlunzhan.com/glossary/kline)重叠的部分」。

系统学习

这个概念属于 [阶段 1·缠论的世界观](https://chanlunzhan.com/learn/worldview)。不讲画法，只讲思路。走势终完美、分类而非预测、级别与递归——这三个观念决定了后面所有技术细节的意义。
