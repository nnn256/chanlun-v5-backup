# 力度

又称 走势力度

衡量一段走势推动强弱的量，缠论用 MACD 柱面积或 DIF 极值来近似。

力度是[背驰](https://chanlunzhan.com/glossary/beichi)判断的核心[量](https://chanlunzhan.com/glossary/chengjiaoliang)。同样是[下跌](https://chanlunzhan.com/glossary/qushi) 10%，用三天走完和用三十天走完，力度完全不同。

原文没有给出力度的唯一定义，实践中常用的近似有：[MACD](https://chanlunzhan.com/glossary/macd) 柱面积、DIF 的极值、走势的斜率、成交量配合。本站的实现同时看柱面积和 DIF 极值，两者满足其一即认定力度衰竭。

力度比较只在同向的[进入段](https://chanlunzhan.com/glossary/jinruduan)与[离开段](https://chanlunzhan.com/glossary/lijinzoushi)之间进行，跨[中枢](https://chanlunzhan.com/glossary/zhongshu)或跨方向比较没有意义。
