# 特征序列

又称 特征元素

线段内部与线段方向相反的那些笔，按顺序排成的序列，用来判定线段是否结束。

向上[线段](https://chanlunzhan.com/glossary/xianduan)的特征序列由其中所有的向下笔构成，向下线段则取向上[笔](https://chanlunzhan.com/glossary/bi)。每一笔作为一个元素，用它的高低点参与后续判断。

特征序列元素之间也要做[包含处理](https://chanlunzhan.com/glossary/baohan)，但规则和 [K 线](https://chanlunzhan.com/glossary/kline)的包含处理不完全相同：本站实现采用严格包含（两侧同时严格）才合并，且第 78 课明确分界点两侧的元素不做合并。

当特征序列出现[顶分型](https://chanlunzhan.com/glossary/fenxing)（向上线段）或底分型（向下线段）时，线段结束。
