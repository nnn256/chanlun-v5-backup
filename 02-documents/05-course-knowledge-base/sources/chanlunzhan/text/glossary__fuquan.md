# 复权

又称 前复权、后复权

把分红送股造成的价格跳空还原掉，让历史价格序列保持连续可比。

股票分红送股会让股价在除权日凭空跳低一截，但持有人的资产并没有减少。如果直接用未复权的价格画图，会出现一个纯粹由技术原因造成的巨大缺口，把结构判断彻底带偏。

前复权是把历史价格按比例调低、保持当前价格不变；后复权反过来。做结构分析一般用前复权，因为当前价格是真实可对照的。本站冻结的日线数据即为前复权序列。
