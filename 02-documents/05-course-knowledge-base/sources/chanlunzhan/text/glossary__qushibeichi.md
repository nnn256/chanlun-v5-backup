# 趋势背驰

在包含两个以上同向中枢的趋势末端出现的背驰，对应第一类买卖点。

[趋势](https://chanlunzhan.com/glossary/qushi)[背驰](https://chanlunzhan.com/glossary/beichi)要求走势已经构成趋势（至少两个依次同向的[中枢](https://chanlunzhan.com/glossary/zhongshu)），最后一段离开走势创出新极值但[力度](https://chanlunzhan.com/glossary/lidu)不足。它是[第一类买卖点](https://chanlunzhan.com/glossary/diyileimaimaidian)的判据。

和[盘整背驰](https://chanlunzhan.com/glossary/panzhengbeichi)的区别不在于形态，而在于语境：是否已经构成趋势。同样的力度衰竭，在趋势末端叫趋势背驰，在[盘整](https://chanlunzhan.com/glossary/panzheng)中叫盘整背驰，两者的结构含义完全不同。
