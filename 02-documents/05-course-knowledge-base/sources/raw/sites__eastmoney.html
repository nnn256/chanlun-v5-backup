东方财富缠论指标：自动画笔、线段和中枢 ​

东方财富怎么自动画缠论的笔、线段和中枢？如果你希望直接在网页 K 线上看到这些结构，可以使用 Struct Guide 浏览器插件，无需在客户端中导入主图公式。

Struct Guide 在受支持的东方财富网页 K 线上自动识别并绘制分型、笔、线段和中枢，普通页面和全屏图表都可使用。 安装后在插件面板中选择图层，无需向客户端导入公式。它运行在网页中，不提供东方财富客户端指标源码。

安装说明 · 画笔与线段效果 · 中枢与全屏设置 · 安装后不显示

画线规则公开： 包含处理、分型、笔、线段和中枢怎样计算，见Struct Guide 画线规则与参数总览。

东方财富自动画笔和线段是什么效果？ ​

在本页支持的个股或指数 K 线中，Struct Guide 把结构叠加在原图上，保留原有 K 线、均线和成交量。分型、笔、线段和中枢可以分别显示或隐藏；进入受支持的全屏图表后，也可以查看这些图层。

在 Struct Guide 面板中分别开启“笔”和“线段”，即可按需要同时显示或只保留其中一层。笔模式从“选项”中选择严格笔或宽松笔，具体条件见笔模式说明，不用在东方财富客户端另外安装一份画笔公式。

笔和线段用实线表示已确认、虚线表示待确认；中枢没有独立确认状态标签。图层开启后是否出现对象，仍取决于输入是否满足识别条件。

东方财富怎么自动画中枢，全屏图也能显示吗？ ​

在插件面板开启“中枢”；只想看矩形时，可隐藏其他结构图层。普通页面与全屏图表都可以使用，但仍须是本页兼容表中的个股或指数 K 线，不能把全屏分时图视为受支持的 K 线图。

显示开关不改变东方财富的数据，也不会强制生成中枢。矩形怎样取上下沿，见中枢画线公式图解；进入全屏后没有显示时，先等待主图加载，再按下方设置与排查说明核对页面和开关。

东方财富缠论指标公式和网页自动画线有什么区别？ ​

使用需求安装前要核对
在客户端导入缠论公式或主图源码客户端是否提供对应编辑入口、公式支持哪些函数与版本
在东方财富网页上显示结构Struct Guide 的浏览器、市场、页面及周期兼容范围
在网页全屏 K 线中继续看图层是否仍为受支持的个股或指数 K 线图

Struct Guide 不提供可导入东方财富客户端的指标源码。客户端公式文件与浏览器扩展使用不同的安装入口，不能互相导入。

支持市场、周期和浏览器 ​

核对项支持范围
市场A股个股页、概念版个股页、指数
周期5分、15分、30分、60分、日线、周线、月线
页面支持的个股和指数 K 线普通页面及全屏图表；分时、盘前、盘后、5日区间、期货、期权及板块汇总页不在支持范围内。

网页上出现某个周期按钮，并不代表 Struct Guide 已适配该周期；请按本页列出的市场、页面与周期范围核对。

支持桌面版 Chrome、Edge、360 浏览器，以及安卓手机上的 Edge。其他手机浏览器、原生行情 App 和桌面客户端不在插件运行范围内。

自动画线怎么打开和设置？ ​

  1. 从安装说明添加 Struct Guide，在扩展管理页确认已启用。
  2. 打开东方财富网页，进入上述范围内的独立 K 线图，等待数据加载。
  3. 在 Struct Guide 面板中分别开启分型、笔、线段和中枢；不需要点击浏览器工具栏图标触发绘图。
  4. 需要更换笔模式时，在选项中选择严格笔或宽松笔，等待重新计算。

更换输入或参数后，等待重新计算，再核对显示结果。参数细则见Struct Guide 画线规则与参数总览。

安装后没有显示，先检查什么？ ​

现象检查顺序
控制面板没有出现浏览器与扩展启用状态 → 页面类型 → 刷新后等待 K 线加载
只有部分图层未出现对应开关 → 图表数据是否满足识别条件
切换图表后像旧结果等待新图表加载 → 核对品种与周期 → 必要时刷新

可换用另一个受支持的浏览器，或暂时停用可能拦截页面脚本的其他扩展，再刷新重试，排查扩展冲突或脚本拦截。

仍有异常时，记录浏览器名称与版本、插件版本、页面地址、品种、周期、复权方式、笔模式、数据范围、面板设置和重现步骤，通过 structguide@outlook.com 反馈工具问题。如附截图，发送前请留意截图中是否包含个人账户信息。

常见问题 ​

全屏图表也能自动画线吗？ ​

受支持的个股和指数 K 线在普通页面及全屏图表中都可以使用。切换显示模式后先等待主图加载，再核对图层开关。这些结构由 Struct Guide 浏览器插件绘制，不能据此理解为东方财富自身提供了相同功能。

为什么分时、盘前、盘后或5日页面没有笔和线段？ ​

这些视图不在插件的结构绘制范围内。请切换到兼容表中的 K 线周期；“5日”行情区间不等于“日线”。

东方财富期货、期权和板块页也能用吗？ ​

它们不在这条东方财富适配路径内。“概念版个股页”是受支持的页面类型，不表示所有概念板块汇总页都支持。期货网页可另查新浪财经缠论自动画线支持说明，两站数据不能视为同一输入。

手机版东方财富 App 能用吗？ ​

Struct Guide 不能安装进东方财富 App。安卓手机使用路径是 Edge 浏览器扩展与受支持的网页图表。

扩展已安装，为什么图上仍没有结构？ ​

先确认浏览器扩展已启用，再确认市场、页面与周期在上方支持范围表内。面板出现但只缺少某一类结构时，检查对应图层是否开启；开关开启也不代表每段数据都会产生该类对象。

东方财富账户和 Struct Guide 账户是同一个吗？ ​

不是同一账户。东方财富网页的数据访问权限由东方财富管理；Struct Guide 的账户、绘制额度及会员功能按插件内页面说明执行。登录或购买 Struct Guide 会员不会解锁东方财富的账户权限或数据服务。

数据范围与使用边界 ​

Struct Guide 只处理当前网页已经加载并展示的 K 线，不提供行情数据。待确认笔或线段可能随输入延伸或调整，端点所在时间不等于取得确认依据的时间；详见笔的确认与更新规则。

东方财富仅为兼容性说明，与本产品无隶属或合作关系。
