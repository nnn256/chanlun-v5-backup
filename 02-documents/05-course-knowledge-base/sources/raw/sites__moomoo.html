moomoo 缠论自动画线：网页版设置、支持市场与周期 ​

如果你找 moomoo 缠论指标，是想在 K 线上自动显示结构，可以了解浏览器插件这种方式。Struct Guide 在 moomoo 受支持的网页单品种 K 线上自动识别并绘制分型、笔、线段和中枢，无需导入指标公式。 它在网页运行，不安装进 moomoo 客户端或手机 App。

安装说明

画线规则公开： 包含处理、分型、笔、线段和中枢怎样计算，见Struct Guide 画线规则与参数总览。

日线与更长周期的图表上可以显示什么？ ​

在本页支持的日线、周线、月线、季线和年线图中，Struct Guide 把结构叠加在网页原有 K 线上。分型、笔、线段和中枢可以分别显示或隐藏；笔模式可选择严格笔或宽松笔，网页原有图层仍保留。

例如需要查看周线图中的笔和中枢时，可在受支持网页选择周线，再在插件面板开启对应图层。显示内容以已识别对象为准，具体操作见本页设置说明；分钟图不在本页支持范围内。

笔和线段用实线表示已确认、虚线表示待确认；中枢没有独立确认状态标签。图层开启后是否出现对象，仍取决于输入是否满足识别条件。

moomoo 网页、客户端和手机 App 怎么区分？ ​

Struct Guide 安装到浏览器，在 moomoo.com 受支持的单品种详情页运行。它不安装进 moomoo 桌面客户端或手机 App，也不把这些客户端中的设置同步到网页。

想使用的环境安装前核对
电脑浏览器中的 moomoo 网页浏览器是否支持，是否进入单品种 K 线
安卓手机的 Edge 浏览器扩展是否启用，是否打开受支持的网页图表
moomoo 桌面客户端或手机 App不在 Struct Guide 运行范围内
moomoo 首页或市场列表需先进入具体品种详情页

不同地区网页的数据可见范围可能不同。插件处理页面已经加载的内容，不额外提供行情或增加网站账户权限。

支持市场、周期和浏览器 ​

核对项支持范围
市场美股、港股、加拿大、日本、澳洲、新加坡、马来西亚、沪深
周期日线、周线、月线、季线、年线
页面单只股票详情页，以及本页展示的 .SPX 指数日线图；分钟图、首页、列表及“5日”行情区间视图不在支持范围内。

网页上出现某个周期按钮，并不代表 Struct Guide 已适配该周期；请按本页列出的市场、页面与周期范围核对。

支持桌面版 Chrome、Edge、360 浏览器，以及安卓手机上的 Edge。其他手机浏览器、原生行情 App 和桌面客户端不在插件运行范围内。

自动画线怎么打开和设置？ ​

  1. 从安装说明添加 Struct Guide，在扩展管理页确认已启用。
  2. 打开moomoo网页，进入上述范围内的独立 K 线图，等待数据加载。
  3. 在 Struct Guide 面板中分别开启分型、笔、线段和中枢；不需要点击浏览器工具栏图标触发绘图。
  4. 需要更换笔模式时，在选项中选择严格笔或宽松笔，等待重新计算。

更换输入或参数后，等待重新计算，再核对显示结果。参数细则见Struct Guide 画线规则与参数总览。

安装后没有显示，先检查什么？ ​

现象检查顺序
控制面板没有出现浏览器与扩展启用状态 → 页面类型 → 刷新后等待 K 线加载
只有部分图层未出现对应开关 → 图表数据是否满足识别条件
切换图表后像旧结果等待新图表加载 → 核对品种与周期 → 必要时刷新

仍有异常时，记录浏览器、插件版本、页面地址、周期、数据范围与面板设置，通过 structguide@outlook.com 反馈工具问题。

常见问题 ​

moomoo 美股、港股 K 线能自动画缠论吗？ ​

在本页支持的日线、周线、月线、季线和年线图中可以使用。其他市场按兼容表核对，并以网页实际能加载的数据为前提。这些结构由 Struct Guide 浏览器插件绘制，不能据此理解为 moomoo 自身提供了相同功能。

moomoo 分钟图为什么没有画线？ ​

分钟图不在这条 moomoo 适配路径内。请使用兼容表列出的周期，不能因为页面有分钟按钮就认定插件支持。

“5日”与“日线”是同一个模式吗？ ​

本工具的支持范围把两者分开：“5日”行情区间视图不支持，日线 K 线支持。没有显示时，先核对所选图表模式。

要下载 moomoo 缠论指标源码吗？ ​

使用 Struct Guide 不需要。它是网页浏览器扩展，不提供可导入 moomoo 客户端的公式或指标源码。

切换市场和品种后，图层需要重开吗？ ​

保持扩展启用，等新图表加载后核对结果即可。若缺少某类结构，检查图层开关、页面与周期；开启图层不会强制产生不满足识别条件的对象。

数据范围与使用边界 ​

Struct Guide 只处理当前网页已经加载并展示的 K 线，不提供行情数据。待确认笔或线段可能随输入延伸或调整，端点所在时间不等于取得确认依据的时间；详见笔的确认与更新规则。

moomoo仅为兼容性说明，与本产品无隶属或合作关系。
