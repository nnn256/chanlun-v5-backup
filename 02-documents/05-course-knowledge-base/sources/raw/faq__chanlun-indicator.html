缠论自动画线软件怎么选：指标公式、网页插件与兼容范围 ​

找缠论指标、自动画线软件或公式源码，是想让 K 线上自动显示笔、线段和中枢，还是需要编辑一份能在指定软件内运行的代码？先分清这两种需求，再依次核对运行环境、显示结果与费用。

Struct Guide 提供浏览器插件这种方式：安装后，在受支持网页的原始 K 线上自动识别并绘制分型、笔、线段和中枢，无需编写或导入公式。 它不安装进通达信等客户端，也不是 TradingView 的 Pine 指标。

想先了解是否收费，可直接看免费画线与 VIP 权益的区别；未购买 VIP 也可在相应绘制额度内使用四类基础图层。

浏览器插件画出来是什么样？ ​

Struct Guide 在网页原图上增加分型标记、笔与线段的连接线、中枢区间，保留 K 线、均线与成交量。四类图层可分别开关，笔模式可选择严格笔或宽松笔。登录后可以保存结构快照并添加备注，结构回放另有试用与会员权限安排，见免费与付费说明。

这类图层由 Struct Guide 提供，不表示行情网站自身提供相同功能。可先看分型、笔、线段和中枢的逐层显示图解，具体功能见缠论自动画线插件介绍，使用位置按下方网站列表选择。

手机版缠论画线工具与电脑端有什么区别？ ​

Struct Guide 支持桌面版 Chrome、Edge、360 浏览器及安卓手机上的 Edge，但使用位置始终是已适配的网页 K 线。手机行情 App 内的指标与浏览器扩展是两种环境，不能因为网页能运行就推定 App 内也能使用。

需要在手机版通达信中导入公式时，应单独核对客户端编辑入口与函数支持，不使用浏览器扩展的安装步骤。

Struct Guide 的使用边界 ​

插件处理当前网页已经展示的数据，在原图叠加图层。它不提供行情数据，不替换客户端功能，也不执行交易。若必须使用某个客户端的原图与数据，网页插件不能满足这项要求；能够接受网页输入时，再继续核对画线方式与会员权益。

比较显示结果时记录什么 ​

运行环境符合需求后，再核对工具怎样画线，以及不同输入和设置会怎样影响显示。

如果你找“笔的划分图解”“线段结束点判断”或“中枢画线公式”，是为了核对软件为什么这样画，可以从Struct Guide 画线规则与参数总览进入对应小节。那里说明本工具的端点条件、确认过程和区间计算，不提供客户端公式下载。

比较前先固定品种、周期、复权方式、数据来源和已加载的历史范围，再记录软件版本与参数。不同数据源或设置下的图形差异，不能只归因于绘图功能。

如果需要了解 Struct Guide 的实线、虚线和更新行为，请查看笔的确认与更新规则及其他对象细则。知识库不重复列出计算阈值。

缠论自动画线可以免费用吗？免费与付费有什么区别？ ​

Struct Guide 的分型、笔、线段和中枢画线不要求先购买 VIP。 未登录的游客和登录后的免费会员，都可在各自的每日绘制额度内使用这些图层。免费使用不等于所有功能、容量和使用期限都不受限制。

付费后会增加哪些内容？ ​

VIP 提供相应的绘制额度、快照容量、使用期限与回放权限；基础四类图层并非 VIP 专属。付费不会增加行情数据、解锁行情网站的账户权限，也不会使未适配的网页或客户端变得可用。识别与绘制条件见Struct Guide 画线规则与参数总览。

免费回放试用从什么时候开始？ ​

登录后首次成功使用结构回放时开始计时；开通或持有 VIP 不会暂停或重置试用期。VIP 到期后是否适用试用或宽限期，取决于此前是否使用过回放；试用、宽限期与到期处理详见用户协议的回放安排。回放可用不等于绘制额度也升级为 VIP 额度。

VIP 到期后，已经保存的快照会马上失效吗？ ​

不会仅因 VIP 到期就重置已有快照的期限。每张快照按服务端创建记录时确定的在线查看、保存与下载期限处理；之后的会员等级变化或续费不会缩短或延长原期限。到期后新保存的快照按免费会员期限执行。

在线查看与保存、下载是两种期限：在线查看期限届满后，不再提供图片在线查看或备注修改，但在保存期限内仍可查看元数据和下载；保存期限届满后，访问与下载停止，并进入清理流程。具体见隐私政策的快照保存说明。

VIP 价格在哪里看，会自动续费吗？ ​

购买前在插件会员入口查看价格、有效期和对应权益。会员通过兑换码开通，自兑换成功之日起算；现行方式不提供自动续费，到期不会自动扣款。计费、续费与退款条件见用户协议。

安装与首次使用的核对顺序 ​

  1. 确认自己使用的是网页图表，而不是手机行情 App 或桌面客户端。
  2. 查阅支持网站与周期，找到对应页面和市场。
  3. 按安装说明启用插件。
  4. 等图表加载后，对照Struct Guide 画线规则与参数总览检查图层与选项。
  5. 在免费额度内核对显示，再从插件会员入口确认所需功能、容量与价格。

需要在通达信内核对源码，可查看通达信近似缠论公式的免费下载、实现说明与网页方案对照。它用于通达信电脑版，不支持手机版，采用与 Struct Guide 网页插件不同的规则。

常见选型问题 ​

找缠论指标，是不是一定要下载源码？ ​

取决于运行环境。使用 Struct Guide 网页插件不需要导入源码；需要修改客户端公式或 Pine 指标时，应核对相应文件是否提供可编辑源码，两者不能混用。

能显示同样的四类图层，结果就应该相同吗？ ​

不一定。数据来源、历史范围、参数与实现方式都可能不同。先核对输入和显示状态，再对照具体规则；不把图层名称一致当作算法一致。

安装前应该先看价格还是兼容范围？ ​

先核对浏览器、网页、市场与周期是否符合使用要求，再按上方免费画线与 VIP 权益的区别确认功能范围，并查看插件内的权益和价格。费用不会改变某个客户端或网页是否被适配。
