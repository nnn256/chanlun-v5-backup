Struct Guide 画线规则总览：包含、分型、笔、线段与中枢 ​

Struct Guide 缠论助手（以下简称插件）的线和矩形为什么画在这里？可以从下面找到对应规则。先看分型，再看笔和线段；如果是矩形的位置有疑问，就看中枢那一页。

插件使用当前网页已经加载的 K 线。下面写的是插件实际采用的画法，参数和显示状态也放在这里，方便查找。

想跟着图例逐步看，可以查看缠论视频讲解：五集分别说明K线包含、分型、笔、线段和中枢，每集附简介、B站链接与文字规则入口。

线段计算依据原文规则实现；原文未明确的处理细节，由插件公开说明实现约定。 局部方向的取值、结束点怎样选择，以及后续数据可能带来的划分调整，都可以在线段规则与图例里逐项核对。

2. 参数总览 ​

第一次使用时，插件采用下面这些设置。如果你已经改过并保存，会沿用保存的选项；可用选项以面板和账户权限为准。

设置初始值影响
笔模式宽松笔切换后重算笔，并更新线段、中枢和有效分型
分型显示范围有效分型只切换绘制集合，不改变结构计算
分型图层关闭控制标记显示，基础识别继续执行
笔、线段、中枢图层打开分别控制显示，不跳过相应计算
颜色方案红涨绿跌只改变配色，不改变对象识别条件

包含处理和线段缺口确认都没有单独的开关。比较其他软件时，除了参数名称，也要看它们各自怎样计算。

3. 实线、虚线和“有效”分别看哪里？ ​

看笔和线段时，实线表示已确认，虚线表示还在等待。分型面板里的“有效”表示这个标记被当前笔采用，其中也可能有待确认笔的端点。中枢矩形没有单独的确认状态标签。

还有一种容易看错的情况：端点画在前面，实线却到后面才出现。因为插件要等后续数据提供确认依据，具体过程可以看笔的确认图解。

4. 为什么会重算 ​

换品种、周期、复权方式，或者加载更多历史 K 线后，插件拿到的数据变了，就需要重新算。切换笔模式也会重算笔和后续结构。只改图层开关或颜色，通常只影响显示。

每个页面、每个周期分别计算。想先确认自己的图表是否支持，可以看支持网站与周期；还没安装的话，从安装说明开始。

5. 画得不一样，从哪里查起？ ​

  1. 先把品种、周期、复权方式和历史范围对齐。
  2. 记下笔模式，以及分型显示的是“有效”还是“全部”。
  3. 沿着分型、笔、线段、中枢往后看，找到最早出现不同的地方。
  4. 留意比较的是实线还是虚线。如果想看它怎样形成，可以用同一份数据做结构回放。

两个软件画得不一样时，也可以按画线差异核对顺序一步步找，通常比只盯着最后的连线更容易定位。
