# 全市场逐日历史回放

入口：`history_replay.py`。它从缓存中的每只股票最早可用日线开始，依次访问每个已闭合交易日；每次只使用从第一根到当日的完整前缀。最终图上的旧端点不回填为过去已经知道的信号。

## 全历史运行

在本目录执行：

```powershell
python history_replay.py --universe runs/tdx-all-a-20261106/universe.json --cache-dir market_data --run-dir runs/history-all-a-fullspan-20261106 --workers 12 --horizons 5,20,60
```

不传`--start-date`时，观察区间就是每股缓存全部可得历史。股票池由提供的`universe.json`固定，不自动刷新或增加其他源。缓存CSV必须与来源元数据SHA-256一致。

单股验证示例：

```powershell
python history_replay.py --universe runs/tdx-all-a-20261106/universe.json --cache-dir market_data --run-dir runs/history-smoke --workers 2 --symbols bj920002,sz000001
```

同一命令可续跑。SQLite中已完成、实现指纹及CSV哈希匹配的股票跳过；`--retry-failed`重做失败股票。每股完成提交一次事务，未完成股票重启时从该股第一前缀重新跑。不要同时启动两个进程写同一个run-dir。

## 数据与输出

- `run.json`：股票池、来源、完整配置和实现指纹。
- `checkpoint.sqlite3`：逐股完成/失败状态，WAL事务。
- `stocks/<symbol>.json`：该股覆盖、首末日期、处理时间、事件数和结果标签汇总。
- `events/<symbol>.jsonl.gz`：只记录信号出现、修订、失效、撤回、再出现，保留真实观察日期。
- `labels/<symbol>.jsonl.gz`：首次成为候选之后，下一交易日开盘至第5/20/60根后的固定窗口标签。
- `summary.json`：已完成覆盖、交易所分布、事件分类、均值与失败清单；运行中逐步更新。

历史证券池仍是本次提供的当前股票清单，包含幸存者偏差，未覆盖退市股票和每个历史时点的真实上市成分。全历史价格覆盖也只等于接口实际返回并验证的首末范围，未独立证明上市首日完整。

## 精确优化与验证

包含栈按原规则增量追加并向左回查，只有受影响的尾部分型重算；MACD保持相同递推顺序。分型不变跳过笔重算，完整笔对象不变时复用结构，仅检查当天价格是否使已有候选失效。笔变化时调用原模块的完整基础线段、中枢和信号逻辑；高层绘图递归不参与基础信号，所以不生成不必要图层。

这不是滚动窗口、抽样日期或近似分段。历史没有被裁短。参考路线`--reference`每日直接调用原`analyze`，供小样本对照。

已执行验证：

- 10项历史回放测试通过，包括随机包含/分型增量完全一致、每前缀信号对象一致、事件前缀不可被未来改变、窗口warm-up、断点和标签汇总。
- `bj920002`591根真实日线完整回放，逐个prefix与原引擎信号对象完全一致。
- `sz000001`前1200根逐prefix与原引擎一致，且包含4条实际信号事件与1次首次候选，避免仅在空信号样本上证明一致。
- `sz000001`全部8485根逐日回放，1000、2000……8000及最后8485根对照原引擎一致；最终CLI实测14.27秒，98条事件、20次首次候选。
- 两股9076个每日prefix完成，SQLite续跑再次执行pending=0。

机器证据：[history-replay-verification.json](artifacts/tdx-integration/history-replay-verification.json)。基准依赖机器负载、笔数和结构复杂度，不能保证所有股票同一耗时。

## 可选观察窗口

`--start-date YYYY-MM-DD`只供明确指定观察窗口时使用：更早的全部日线仍输入一次基线，之后每日都使用全历史前缀；不将基线已存在信号当新入场，也不推断窗口前的首次出现。用户要求全历史时不传此参数。

## 标签的边界

标签均从当时第一次观察为有效候选后的下一根开盘开始。未来数据只交给独立评估函数，不参与信号生成。常数成本默认往返20基点，可配置。

该结果是事件研究标签，不是组合收益回测。信号可重叠；T+1、ST本金与特殊涨跌停、停牌与退市、融券、成交冲击、真实滑点、分红再投资等没有完整模拟。卖侧方向标签不代表可卖空。日线非复权数据还需保留公司行为造成的结构跳变影响。
