# 工作台2.1：完整历史、全周期及历史分时

入口仍为 http://127.0.0.1:8791 。打开300949：http://127.0.0.1:8791/?symbol=sz300949 。

上版的问题：计算使用接口可取的全部历史，但图表JSON仅保留最近180根日线、280根30分钟和420根5分钟，所以拖动无法看到更早K线。上版也只接入这三个周期，不能称为所有周期均已完成。

现在图表载入整个已核验序列及对应结构，可使用“全部历史”“最近200根”、放大缩小、滚轮、拖动和日期定位。日期定位只改变查看窗口，不会把最终结构当成当时确认；历史因果分析仍使用独立逐日回放任务。

“全周期历史”任务实时请求TDX的日、1分、5分、15分、30分、60分、周、月、季、年K线，并以最早日线为起点每5个交易日聚合5日K线。5日K线不是周线，“五日分时”则是最多5个交易日价格快照的连续视图，三者分别显示。全周期任务还逐日请求已返回日线范围内的历史分时。缺失、失败日期分别保留。

每个周期都有独立数据范围，接口返回的全部历史不等于自上市起所有分钟K线。300949本轮获取范围：

| 数据 | 本轮返回 |
|---|---|
| 日线 | 2021-02-26—2026-11-06，1,381根 |
| 历史分时 | 同一范围，1,381天 × 240点 = 331,440点；每天收盘价与日线一致 |
| 原生1分钟 | 2026-06-22—2026-11-06，22,560根 |
| 原生5分钟 | 2024-10-31—2026-11-06，23,520根 |
| 原生15分钟 | 同一范围，7,840根 |
| 原生30分钟 | 同一范围，3,920根 |
| 原生60分钟 | 同一范围，1,960根 |
| 原生周／月／季／年 | 292／70／24／6根；形成中的周期排除于结构计算 |
| 聚合5日K线 | 277根，最后不足5个交易日的一根形成中 |
| 历史竞价 | 现有TDX接口不提供，明确显示不可用 |

分时只提供每分钟价格及成交量快照，不包含该分钟完整开高低收。因此不拿2021年的分时快照伪造2021年的1分钟K线；也不把9:31的数据冒充9:15—9:25的竞价记录。

“每15秒更新报价”更新当前股票接口报价，显示获取时间，并提示休市可能是最后交易日报价。完整结构通过“刷新该股全部周期”任务重新计算；报价刷新不冒充结构已经重算。单股任务具有独立通道，不必等全市场逐日回放结束。

原V2核心未改动。新周期复用同样的结构原语；周/月/季/年及5日周期单独做完成性检查，形成中的K线用于展示但不参与确认。多周期触发仍明确采用日线→30分钟→5分钟，不能宣称所有新周期都建立了理论级别递归对应。
