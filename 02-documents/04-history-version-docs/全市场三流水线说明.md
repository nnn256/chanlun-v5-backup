## 可复现命令

先启动本机数据服务：

```powershell
.\Start-TdxApi.ps1
```

在本目录运行三项。新批次应换新的run目录；下例展示本次已经启动的路径，不应同时再启动重复写同一目录的进程。

```powershell
python market_scan.py --run-dir runs/tdx-all-a-20261106 --workers 8
python intraday_scan.py --universe runs/tdx-all-a-20261106/universe.json --run-dir runs/tdx-intraday-all-a-20261106 --workers 8 --as-of 2026-11-06T02:03:45+08:00

```

历史命令**没有**`--start-date`，没有把较早行情仅用作预热、没有滚动截短、没有隔日抽样。`visited_daily_prefixes`应与成功证券的`history_bars`相同，`warmup_bars`为0。

日线、分钟的恢复分别加`--resume`；历史回放以相同命令重启即读取逐股完成检查点，失败重试加`--retry-failed`。全部流水线必须使用对应原run记录的配置、截止时间和代码版本；生产代码变更时需明确重新计算或新建run。

## 各种“历史”的含义

日线的“all”是通达信服务器提供的所有页。平安银行样本可取得8485根、起于1991-04-03；这不证明每只股票都覆盖其上市首日，也不代表当前股票池含所有已退市历史证券。

分钟样本只覆盖约两年：平安银行30分钟3944根、5分钟23664根，起于2024-10-25。因此比分钟历史更早的日线候选不能做分钟内部结构验证，结果标记`insufficient_child_history`。不得补零或拿后来分钟结构回填历史。

历史回放的信号只依赖从首根到当日的K线；未来数据只在独立结果标签步骤使用。输入本身是现在取得的历史版本，仍可能有数据源修订、复权口径和当前股票池幸存者偏差。本次使用未复权数据，除权价格跳变会影响结构，需结合相关数据再解释。

## 事件和评估

每股事件保存在历史run的`events/<代码>.jsonl.gz`，结果标签在`labels/<代码>.jsonl.gz`。事件包括出现、修订、撤回、重新出现及失效；旧事件不被事后最终图覆盖。首次候选的假设入场以**下一根K线开盘**开始，5/20/60以实际可得交易K线根数计。

评估是固定窗口事件标签，默认常数往返成本20基点。它没有完整模拟涨跌停、停牌、T+1、融券、盘口冲击或组合资金分配；信号可能重叠，不将平均方向收益称为可实现组合收益。买卖点仍是研究候选，`execution_allowed=false`。

## 核验

```powershell
python tools/verify_market_run.py --run-dir runs/tdx-all-a-20261106 --cache-dir market_data --sample 20
python tools/verify_intraday_run.py --run-dir runs/tdx-intraday-all-a-20261106 --cache-dir market_data --sample 20 --workers 4
python tools/verify_history_run.py --run-dir runs/history-all-a-fullspan-20261106 --cache-dir market_data --daily-run runs/tdx-all-a-20261106 --sample 20
```

核验检查当前股票池、记录版本、缓存SHA-256、原始响应、数据时段、行情字段和结构摘要。逐日事件检查用实际CSV的时间与下一根开盘重新核对；抽样和全量哈希验证的范围分别列出，不把抽样称为所有股票双重全回放。
