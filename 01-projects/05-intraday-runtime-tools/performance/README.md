# 全历史分时研究：确定等价性能修复

修改范围只包括计算缓存/分组：

- `chanmodel/intraday_research.py`：共享每个日期/周期的不可变交易网格（512项上限）；每根K线用集合检查原生闭合时刻；交易分钟使用二分计数；评估一次解析输入时间、按日分组，第一次遇到某日提醒时准备完整性/低高价/网格位置。价格过滤、原生类型、失效/撤回、下一根开盘、滑点、T+1及未来窗口规则均未变。
- `tools/verify_intraday_research.py`：独立核验仍从原始K线重算全日高低和完整性，改为按日准备一次；不导入研究评估的标签结果作为真值。
- `tests/test_intraday_performance.py`：5项新增非空/日历边界测试，与13项原研究测试共18项通过。

## 确定等价证据

真实本地 `sz300949`，全部22,560根1分钟K线，从最早可得日期开始（未截短热身、无“只跑最近60天”）：旧、新完整会话快照、全部事件及所有评估行逐字段相等。1,286条生命周期事件，600条研究提醒，593个同日下一开盘假设。规范JSON同SHA256：

`81ef1e73124069d880b95aec9019ade00b053b49355987b84973bb21bbca7c73`

全部23,520根5分钟数据上保存的126条事件/46条提醒，旧、新评估也逐字段相等。完整来源、各版本哈希和评估七次重复时间见 `equivalence.json`。

## 计时结果与边界

| 范围 | 原耗时 | 优化耗时 | 说明 |
|---|---:|---:|---|
| 1m事件评估 | 中位0.35155秒 | 中位0.09163秒 | 7次顺序重复，3.84倍 |
| 5m事件评估 | 中位0.03177秒 | 中位0.02413秒 | 7次顺序重复，1.32倍 |
| 独立原始全日极值复核，593行 | 6.6077秒 | 0.02856秒 | 231.4倍，仅该核验子步骤 |

完整回放cProfile原366.6秒、优化301.5秒是并发运行时诊断数字，不能当隔离吞吐基准；两者输出完全相同。最大剩余热点是固定原生引擎 `snapshot/make_report` 的全图构造（旧3073次，约224秒；新同3073次），本次没有改变原生算法/结构判断或擅自跳过几何复核。
