# 本地历史 API 与离线完整包

程序始终在本机运行 API。默认 `127.0.0.1:8791`，端口占用时会分配可用端口，以启动窗口/desktop-status.json为准。行情供应商断开时，勾选“本地历史模式”从已有CSV/元数据或认证CHJ7会话构图，不必等待网络；显示真实历史日期，不视为当前报价。

初次单股结构从本地全历史构建，接口返回202后台任务并显示进度；之后校验内容后复用结果。大目录清点和ZIP导出也在后台，不占用首页60秒实时等待。

## 现有历史 ZIP

数据页“本地历史记录”可清点、导出单股或全部保存文件，支持原始周期。仅按证券/周期选择一份通过内容校验的完整来源，不重复打包多任务同源历史。形成中的原始行保留，但离线结构只使用保存的闭合前缀。

导出包含CSV、白名单元数据、原始供应商响应和manifest/SHA。用户数据库、设置、令牌、程序代码及任意路径不会混入历史包。只能证明保存文件内容相符，不能证明供应商上市以来无缺失或历史退市成分完整。

已实际导出的全市场日线为5,580只、17,083,571根闭合K线、0失败，ZIP996,184,686字节；各股最新缓存日期不同，不能称当前全市场行情。

另一台电脑：把EXE与导出的历史ZIP放一起，使用随交付的“启动本地离线版.cmd”；它会通过 `--import-history` 校验导入到新历史任务目录，不覆盖旧缓存。也可以直接运行：

```powershell
ChanlunWorkbenchV4.exe --offline --import-history "history-day-all-....zip"
```

## 运行环境和保护

Windows x64安装包和单EXE带Python3.11、Tcl/Tk、VC runtime DLL、TDX以及CPU/CUDA适配器，不需要预装Python/pip，也不需要为本程序执行不明网络安装脚本。缺失静态资源、未运行占用的损坏TDX可从内置认证内容自动恢复。被占用的损坏文件先正常退出再重启；GPU另需电脑已有NVIDIA驱动，CPU模式不要求它。

资源包使用Windows CNG AES-256-GCM加密及认证，篡改验证失败不会执行。自有Python模块在EXE的PYZ字节码内，不再向新用户数据目录释放`.py`；固定第三方MIT源供原生哈希校验，浏览器HTML/JS/CSS仍可审查。旧版本已释放的源码不会主动删除。

嵌入式密钥最终可以被控制本机的人提取，因此这里只提高静态复制和提取门槛，不承诺绝对防逆向，也不冒认正式代码签名或许可授权系统。用户历史ZIP默认可解压，便于跨设备复核和迁移；算法保护不把用户数据锁死。
